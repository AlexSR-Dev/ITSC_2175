12 - 3.2 - Union and Intersection:

The set intersection operation:
Let A and B be sets.

- ∩, AND
Intersection - Of A and B, denoted as A ∩ B. Reads "A intersect B", is the set of all elements that are elements of both A and B.

Intersection operation can also apply to infinite sets:
A = {x ∈ Z : x is an integer multiple of 2}
B = {x ∈ Z : x is an integer multiple of 3}
A ∩ B = {x ∈ Z : x is an integer multiple of 6}
- A ∩ B is the set of all integers that are both an integer multiple of 2 and an integer multiple of 3, which is exactly the set of all integers that are multiples of 6.


- ∪, OR
Union - Of A and B denoted A ∪ B. Reads "A union B", is the set of all elements that are elements of A or B.
- Inclusive, combines all elements of the set into one.

A special noation allows for a compact representation of the intersectio of a long sequence of sets: A_1, A_2,..., A_n.

Intersection:
n

i=1

n
