1.6: Predicates and Quantifiers:

Predicate - A logical statement with a truth value that is a function of one or more variables.
Predicates become propositions once all variables are bound. However, for how the proposition can be true depends entirely on statements provided.

EX: Q and R are the predicates with variables.
Q(x, y): x^2 = y

R(x, y, z): x + y = 2

The proposition proposed would be like Q(5, 25), which would be true as 5^2 = 25.
The proposition proposed for the second predicate would be like R(2, 3, 6), which would be false as 2 + 3 != 6.


Domain - Of a variable in a predicate is the set of all possible values for the variable.
- The domain should be provided as part of the definition of the predicate.

EX: The domain for all the variables in the predicate is the set of positive integers:
P(x) : x is a prime number.
L(x, y) : x < y
S(x, y, z) : x^2 + y^2 = z^2

Is L(6, 6) true or false?
- False, since both parameters are equal rather than less than the other.

2) 1/(1 + x) < 1.
- Proposition, as the statement is true for all values in the domain, but remains a predicate for the variable.

Universal quantifer:
- When all the variables in a predicate are assigned a specific values from their domains, then the predicate
becomes a proposition with a well-defined truth value.
- Every single element from the domain must be evaluated as true for the predicate to be true.
- Also you can turn a predicate into a proposition by using a QUANTIFIER.



Counterexample - For a universally quantified statement is an element in the domain that results in the predicate as false.
- For universally quantified statements a single counterexample is enough.
EX: Truth values for universally quantified statements:
- The domain is the set of all positive integers:

1) ∀x(x^2 > 0)
- Reads as for ALL sets of all positive integers, x^2 is greater than 0.
- True, as every false past and including one greater than 0.

2) ∀x(x - 1 > 0)
- Reads for ALL sets of all positive integers, x-1 > 0.
- False, as 1 is the only element that isn't greater than 0, resulting in the proposition as false.


-------------------------------------------------------------------------------------------------------------------------

Existential Quantifier:
- The proposition is true for at least one possible value for x in its domain.
The counterexample
- Would be if the domain of variable x is empty, in that there is no element in the domain for the proposition to be true.
EX: Truth Values for existentially quantified statements:
- The domain is the set of all positive integers.

1) ∃x(x^2 < 0)
- Reads as for some set of all positive integers, x^2 is less than 0.
- False, as there isn't any element in the set to prove a single true truth value.

2) ∃x(x^2 = x)
- Reads as for some set of all positive integers, x^2 is equals to x.
- True, as 1 is the only elemen to be equal to itself when squared.

1.7: Quantified Statements:

Quantifiers - The generic term for universal and existential quantifiers.
EX: ∃x or ∀x
Quantified Statements - A logical statement that includse a universal/existential quantifier.
EX: ∀x(P(x) V Q(x))

EX: Evaluating Quantified Statements:
- The domain for the variable x is the set of all positive variables.
Predicates:
O(x) : x is odd.
M(x) : x is an integer multiple of 4 (e.g, 4, 8, 12, ...).

1) ∃x(O(x) ∧ M(x))
- Reads as, for Some set of all positive variables, x is odd AND x is an integer multiple of 4.
- False, since there are multiple counterexamples for this proposition and not a single proposition can be true.
As there is no positive integer that is a multiple of 4 and odd.


2) ∃x(-O(x) ∧ -M(x))
- Reads as, for SOME sets of all positive variables, x is NOT odd AND x is NOT an integer multiple of 4.
- True, as there are multiple counterexamples for this compound, for instance 6 is even and not a multiple of 4.


3) ∀x(M(x) → -O(x))
- Reads as, for ALL sets of all positive variables, if x is an integer multiple of 4, then x is NOT odd.
- True, as every integer that is a multiple of 4 is even.


4) ∀x((x = 1) V (x^2 != x))
- Reads as, for ALL sets of all positive variables, x is equals to 1 OR x^2 cannot equal to x.
- True, since the operator is OR, only one proposition needs to be true for the result to be true.

Free Variable - A variable is free to take on any value in the domain.
EX: ∀xQ(x) V R(x), R(x) is a free variable.

Bound Variable - A variable that is bound to a quantifier.
EX: ∀x(Q(x) V R(x)) or ∀xQ(x), are both bound to thier quanifier as their coefficient or surronded by it.

Scope - The quantifier is part of the logical expression to which the quantifier applies.
For instance in the previous free variable example, R(x) is outside of the quantifiers scope, thus the expression is not a proposition. In contrast for the bound variable example, both vars are bounded thus qualifies as a proposition.

NOTE: Expressions with FREE variables AREN't propositions.
NOTE: Expressions with the scope of the universal quantifier in the statement is a proposition.
