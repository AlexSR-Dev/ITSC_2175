3.4.2: Sets of sets:
Consider the following sets:
A = {3,4,{3,4},{1,2,3},5}

1) The cardinality of A is 5.
- True, as there are 5 element separated by a commas with the exception of the existing sets in {}.

2) {3} ⊆ A
- True, 3 is an element of set A, thus it is also a subset.

3) {1} ⊆ A
- False, 1 ∉ A, so {1} ⊈ A.

4) {1,2,3} ⊆ A
- False, the set {1,2,3} consists of the elements 1,2, and 3.
BUT, 1 and 2 are not elements of A. Thus {1,2,3} ⊈ A.

5) {5,{3,4}} ⊆ A
- True, as 5 ∈ A and {3,4} ∈ A, so this set is a subset of A.



Power set - Denoted by P(A) for set A, is the set of all subsets of A.
EX: A = {1,2,3}, then P(A) = {∅,{1},{2},{3},{1,2},{1,3},{2,3},{1,2,3}}

Since |A| = 3, the cardinality of the power set of A is 2^3 = 8.


3.4.4: Power Sets:
Consider the following set: A = {2,3,5,7,14}
1) 2 ∈ P(A)
- Reads "Is 2 an element of power set A?"
- FALSE, the elements of P(A) are all subsets of A. 2 is an element of A, which is 2 ∈ A.

2) {2} ∈ P(A)
- Reads "Is subseat 2 an element of power set A?"
- TRUE, {2} ⊆ (a subset) A, thus, {2} ∈ P(A).

3) {2,3} ∈ A
- Reads "Is subset {2,3} an element of set A?"
- FALSE, this subset is a subset of power set A, not set A.

4) {2,3} ∈ P(A)
- Reads "Is subset {2,3} an element of power set A?"
- TRUE, this subset is found in the power set A.

5) |P(A)| = 32
- 5 seperate elements are found in set A. |A| = 5
- However the cardinality of power set A is 2^5 = 32.
- TRUE, |P(A)| = 32
