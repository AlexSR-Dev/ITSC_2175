13 - 3.3 - More Set Operations:

Set difference and symmetric difference:

Difference - Between two sets is denoted by A - B.
- The set of elements that are in A but not in B.
- The difference operation is not commutative since A - B = B - A is not always true.

Symmetric Difference - Betweem two sets is denoted by A ⊕ B.
- The set of elements that are in either A or B, but not both.
- Is commutative.

Alternative defintions of Symmetric Difference:
A ⊕ B = (A - B) U (B - A)




The Set Complement Operation:
- A n B is well-defined if U is unknown, as long as A and B are well-defined.
- By contrast, determining the complement of a set requires that the universal set be well-defined.

Complement of a set - Denoted as Ā.
- Is the set of all elements in U that are not elements of A.
EX:
A = {x ∈ Z : x is odd}
- The complement of A is the set of all even integers.






Summary of Set Operations:

      Operation     |   Notation    |     Description

----------------------------------------------------------------------------
      Union         |   A U B       |   {x : x ∈ A or x ∈ B or both}

    Difference      |   A - B       |   {x : X ∈ A and x ∉ B}
----------------------------------------------------------------------------

    Complement      |     Ā         | {x : x ∉ A}
