10 - 2.3 Gates and Circuits

Boolean Algebra is used to describe and design circuits used in electronic devices.

Circuits are built from electrical devices called 'gates'.
GATES - Receives some number of boolean input values and produces an output based on the values of the inputs.
- Implements a simple boolean function.

Three types of gates perform the three basic Boolean operations:
- AND gate computes Boolean multiplcation.
- OR gate computes Boolean addition.
- INVERTER computes the complement.

The Shape of the gate indicates the particular operation the gate computes:
- AND gate: "The tip of a finger" results xy.

- OR gate: "A sort of boomerang" results x+y.

- Inverter: "A triangle" results -x.

- All of these shapes are sideways.

Combinatorial Circuit - The output of the circuit depends only on the present combination of input values and not on the state of a circuit.
- Cannot store information over time.
- Store a single bit of information, such as a loop.

1) Circuit 1 is supposed to compute (x+y)(-x)(-z). What is the correct type for Gate A?
- OR, "Boomerang" as (x+y) is found initially at gate A.

2) Circuit 1 is supposed to compute (x+y)(-x)(-z). What is the correct type for Gate B?
- AND, "Finger Tip" as it would combine (x+y)(-x) with the -z at the other end.

3) Circuit 2 is supposed to compute ((-x) + y)((-y) + z). What is the correct type for Gate C?
- OR, "Boomerang" as the sequence ((-y) + z) is found at gate c, thus corresponds to OR to complete that portion.

4) Circuit 2 is supposed to compute ((-x) + y)((-y) + z). What is the correct type for Gate D?
- AND, "Finger Tip" as it with allow multiplication to the the two expression at gate D.



Designing Circuits:
Steps in the circuit design process.

1) Build an input/output table with the desired output for every possible combination of values for the input variables.
2) Construct a Boolean expression that computes the same function as the function specified in the input/output table.
3) Construct a digital circuit that realizes the Boolean expression.
