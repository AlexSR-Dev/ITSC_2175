More Notation Related to Sets:
∈ - Indicates that an element is in a set.
∉ - An element is not in a set.

Empty Set - A set with no elements, denoted with symbol: ∅.
Null Set - Another various of an empty set, denoted by {}.

finite set - A set that is either empty of whose elements can be numbered 1 through n for some positive integer n.
infinite set - A set that is not finite.

Cardinality:
- Of a finite set A, denoted by |A|, is the number of distinct elements in A.
EX: If A = {2,4,6,10}, then |4| = 4.
- The cardinality of the empty set |∅| is zero.

(...) - Denotes long possibly infinite sequence of numbers, but the sequence's pattern should be clear.
EX:
B = {1,2,5,...,99}
C = {3,6,9,12,...}


Two sets are equal if they have exactly the same elements:
D = {3,4,5}
E = {5,3,4}
F = {5,3,4,6}

D = E because for any a, a ∈ D if and only if a ∈ E.
F != E because 6 ∈ F but 6 != E.

Universal set - Denoted by the variable "U", is a set that contains all elements mentioned in a particular context.
EX: discussion about certain types of real numbers, any element in the discussion is understood to be a real number. In this case, the universal set is the set of real numbers.
In a discussion regarding the academic standing of students at a school, the universal set is the set of all students enrolled in the school.

Subset: ⊆
- If every element in A is also an element of B, then A is a subset of B, denoted as A ⊆ B.
- If an element in A is not of B, then B is not a subset of B, denoted as A ⊈ B.
- If the universal set is U, then for every set of A: ∅ ⊆ A ⊆ U.

Proper Subset: ⊂
- If A ⊆ B and there is an element of B that is not of A, then A is a proper subset of B, denoted as A ⊂ B.

Equal:
- On if two sets are subset of each other: A = B if and only if A ⊆ B and B ⊆ A.


3.1.9: Sets and Subsets:
Consider the following sets:
A = {3,4,5}
B = {4,5,3}
C = {x ∈ Z : x is odd}
D = {3,5,7,9}

1) A ⊂ B?
- No, its a subset intead (⊆), as A has every element that set B has.

2) A ⊆ B?
- Yes, every element in A is in B.

3) C ⊂ Z?
- Yes, as this proper subset and not all integers in Z are in C's set.

4) B ⊆ D?
- No, as element 4 isn't in set D.

5) D ⊆ C?
- Yes, every element in D is in set C, however it wouldn't be equal.

6) N ⊂ Z ⊂ Q ⊂ R?
- Yes, natural numbers are a proper subset of integers. Integers are a proper subset of rational numbers. Rational numbers are a proper subset of real numbers.

7) Is the following statement true?
For any two sets, X and Y, of X ⊂ Y, then X ⊆ Y.
- Yes, if X is a proper subset of Y, then every element of X is also an element of Y, thus a subset.

8) Is the following statement true?
For any two sets, X and Y, if X ⊆ Y, then X ⊂ Y.
- No, as if X = Y, X ⊆ Y, but X ⊄ Y.
