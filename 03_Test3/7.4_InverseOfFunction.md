7.4 - Inverse of a Function

GOALS:
- Determine if a function has a well-defined inverse.
- Calculate the inverse of a function at a specific value.
- Describe the input/output relationship of the inverse of a function.
- Solve for the inverse of a function with an infinite domain analytically.


-------------------------------------------------------------------------------------------------------------------------------

1. Defining the Inverse of a Function
SUPPOSE: A function is defined as: f : X -> Y
• X is the domain, or set of possible inputs.
• Y is the codomain, or set of possible outputs.

- If f is a bijection, its inverse is obtained by exchanging the entires in every ordered pair.

NOTATION of INVERSE (f^-1):
f^-1 = {(y,x) : (x,y) ∈ f}

EX: Suppose the original function is: f = {(1,7),(2,9),(3,8)}
- Each ordered pair is in form: (input, output)

INVERSE: f^-1 = {(7,1),(9,2),(8,3)}


1.2) Does a Function Have an Inverse?
- f has an inverse if and only if f is a bijection.
THUS: Must have One-to-One and Onto.

- There are no repeated inverse inputs with different outputs and every element of the original TARGET is represented.

3. Participation Activity 7.4.2 - Does a Function Have an Inverse?
ASKS: Determining whether a function is a bijection.

Q1) Arrow Diagram
- Determine whether the function represented by the arrow diagram has an inverse.
APPROACH:
1) Check whether any two elements of the domain point to the same element in the TARGET.
2) Check whether every element of the TARGET has an incoming arrow.
3) Conclude that an inverse exists only if both conditions hold.

STEP 1: Domain & Target
A = {a,b,c,d}
X = {v,w,x,y,z}

ARROWS: a -> x, b -> v, c -> z, d -> w

Step 2: Onto
- Element y has no incoming arrow.
THUS: The function is not ONTO X.
RESULT: No


Q2) A Function on a Finite Set
X = {u,v,w,x}
DEFINES: g = {(u,v),(v,w),(w,w),(x,u)}
AKS: Does g have an inverse?

- Determine whether g is a bijection.
STEP 1: Check whether the function is one-to-one
g(u) = v
g(v) = w
g(w) = w
g(x) = u

NOTE: g(v) = g(w) = w
AND: v != w
- Two different inputs produces the same ouput.
THUS: g is NOT one-to-one


STEP 2: Check the reversed pairs
g^-1 = {(v,u),(w,v),(w,w),(u,x)}

- The input 'w' is associated with two outputs: w -> v & w -> w.
THUS: The reversed relation is not a function.
RESULT: No


Q3) An Infinite Domain
DEFINES: h : Z -> Z , h(x) = -x

ASKS: Determine whether the function is a bijection over the integers.

STEP 1: Understand the rule
- The function chnages an integer to its negative.
EX: h(3) = -3

STEP 2: Check whether it is one-to-one
SUPPOSE: h(a) = h(b)
THEN: -a = -b   -> *(-1) -> a = b
THUS: h is one-to-one


STEP 3: Check whether it is onto
- Every integer y has an integer input x = -y that: h(x) = -(-y) = y
THEN: Every integer in the TARGET is reached.
THUS: h is onto.
RESULT: Yes

4. Inverse in Function Notation
- For a bijection f : X -> Y
: f(x) = y <--> f^-1(y) = x

<--> "if and only if"
MEANING:
• Original function maps x to y.
• Inverse function maps y back to x.


4.1) The Inverse Undoes the Original Function
: f^-1(f(x)) = x
MEANS: You apply the original function first and then apply its inverse.

EX:
SUPPOSE: f(2) = 7
THEN: f^1(7) = 2
THUS: f^1(f(2)) = f^1(7) = 2

6. A Function That Requires a Restricted Domain
CONSIDER: f : R -> R
DEFINE BY: f(x) = x^2

7.1) Why f(x) = x^2 Does Not Have an Inverse on R.
- Consider the inputs x and -x
f(x) = x^2
AND:
f(-x) = (-x)^2 = x^2
THUS: f(x) = f(-x)


EX: f(2) = 4
AND: f(-2) = 4
- The function is not one-to-one

THUS: This function does not have an inverse.


7.2) Restricting the Domain to Positive Reals
FUNCTION: f : R^+ -> R^+, f(x) = x^2

STEP 1: Begin with the function
y = x^2

STEP 2: Solve for x
- Taking the square roots: x = ±sqrt(y)
- Since its just positive real numbers: x = sqrt(y)

STEP 3: Write the Inverse
f^-1(y) = sqrt(y)
f^-1(x) = sqrt(x)

STEP 4: Verify
- For positive x
f^-1(f(x)) = sqrt(x^2)


EX:
f : R -> R, Where f(x) = -x + 3. What is f^-1?

1) y = -x + 3 for x is x = -y + 3.
2) f^-1(y) = -y + 3.
3) f^-1(y) = -y + 3 == f^-1(x) = -x + 3
- f(x) and f^1(x) are the same function.
