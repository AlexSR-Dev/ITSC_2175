8.2 - Recurrence Relations

GOALS:
• Find terms in a sequence defined by a recurrence relation.
• Determine the number of initial values required to define a sequence using a recurrence relation.
• Derive a recurrence relation and initial values that model a real-world scenario.


-------------------------------------------------------------------------------------------------------------------------------


1. Recuurence Relations: Fundamentals
- A rule that defines a term of a sequence as a function of one or more previous terms in that sequence.

THUS: In arithmetic sequence, each number is obtained by adding a fixed value to the previous number.

DEFS and NOTATIONS:
a_n - The term at index n.
a_0 - The initial term when the sequence begins at index 0.

Initial value - A specified term needed to begin calculating the sequence
Recurrence Relation - A rule expressing a term using one or more previous terms.

n - The index identifying the term being defined.
n >= 1, n >= 2, etc. - The condition specifying when the recurrence rule applies.



NOTE: Recurrence relations need both an initial value and a rule for calculating later terms.
EX: rule - a_n = a_(n-1) + 3, with a_0 = 2
THUS: a_1 = 2 + 3 = 5
SEQUENCE: 2, 5, 8, 11


-------------------------------------------------------------------------------------------------------------------------------


2) Recurrence Relation Defining an Arithmetic Sequence
a_0 = a (initial value)
a_n = d + a_(n-1), n >= 1

- a is the initial value
- d is the common difference
- a_n is calculated by adding d to the previous term

EX: a_0 = 4 and d = 3
CALCULATE: 
a_0 = 4
a_1 = 3 + 4 = 7
a_2 = 3 + 7 = 10, etc.


-------------------------------------------------------------------------------------------------------------------------------


3) Recurrence Relation Defining a Geometric Sequence
a_0 = a (initial value)
a_n = r * a_(n-1), n >= 1

- a is the initial value.
- r is the common ratio.
- Each term is obtained by multiplying the previous term by r.

EX: a_0 = 3 and r = 2
CALCULATE:
a_0 = 3
a_1 = 2(3) = 6
a_2 = 2(6) = 12, etc.


-------------------------------------------------------------------------------------------------------------------------------


4) The Fibonacci Sequence
EX: Model of rabbit population growth.

- Let f_n be the number of pairs of rabbits at the end of month 'n'.
INITIAL VALUES: f_0 = 0,  f_1 = 1

RECURRENCE RELATION: f_n = f_(n-1) + f_(n-2),  n >= 2
- Each term is the sum of the previous two terms.

CALCULATE:
f_0 = 0
f_1 = 1
f_2 = f_1 + f_0 = 1 + 0 = 1
f_3 = f_2 + f_1 = 1 + 1 = 2
f_4 = f_3 + f_2 = 2 + 1 = 3, etc.
0,1,1,2,3,etc.

6) Participation Activity 8.2.3 - Initial Values for Recurrence Relations
ASKS: How many initial values must be given for the sequence to be well defined for all n >= 0?

Q1) c_n = 3 * c_(n-1) + 2 * c_(n-2)
REASON: The recurrence uses both c_n-1 and c_n-2.
THUS: To begin calculating terms, the two starting values c0 and c1 are needed.
RESULT: 2

Q2) d_n = (n-1) * d_(n-2)
REASON: The recurrence refers to the term two indices earlier.
THUS: With d0 and d1 provided, the recurrence is applied from the valid starting index.
RESULT: 2

Q3) b_n = b_(n-3) * b_(n-2)
REASIB: The recurrence uses terms three and two indices earlier.
THUS: The three starting terms b0, b1, b2 are needed to calculate b3 and all subsequent terms.
RESULT: 3

7) Dynamical Systems
- Is a system that changes over time, where its start at any point is determined by a set of rules that depend on past states.

Discrete-Time Dynamical System
- Time is divided into discrete intervals. The state during one interval is a function of the states in previous intervals.

NOTE: History of the system is represented by a sequence of states indexed by nonnegative integers.

EX: Rabbit Population
- For the Fibonacci rabbit model:
: Time interval: a month.
: State: The number of pairs of rabbits.
: Sequence: f_0, f_1, f_2,...
: Ruke: f_n = f_(n-1) + f_(n-2)

8) Participation Activity 8.2.4 - Defining Sequences by Recurrence Relations
- Select a recurrence relation that matches a real-world scenario.

Q1) Let s_n be the salary of an employee in year n. The employee receives a $1,000 bonus in December.
The salary for the next year is 5% more than the income received by the employee in the previous year (including salary and bonus).

STEP 1: Calculate the previous year's total income.
s_(n-1) + 1000

STEP 2: Increase that total by 5%
s_n = 1.05(s_(n-1) + 1000)


Q2) 25% of the yeast cells in a petri dish divide every hour. When a single cell divides, it becomes two cells, instead of one
and the number of cells increase by one. Let y_n be the number of yeast cells in the petri dish after 'n' hours.

STEP 1: Identify the fraction of cells that divide.
25% = 0.25

STEP 2: Determine the increase in the total number of cells.
- Each dividing cell adds one cell to the total.
0.25y_(n-1)

STEP 3: Add the increase to the existing population.
y_n = y_(n-1) + 0.25y_(n_1)
= (1 + 0.25)y_(n-1)
