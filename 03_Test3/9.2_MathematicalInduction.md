2. Introduction to Mathematical Induction
- Is a proof technique used to establish that a statement is true for every positive integer.

Inductive Proof - Establishes that a statement parameterized by an integer 'n' is true for all positive integer values of 'n'.

2.2) Two Components of an Inductive Proof
a) Base Case
- Establishes that the theorem is true for the first value in the sequence.
EX:
- Amal receives three wishes on day 1.
THUS: The statement is true for n = 1.

b) Inductive Step
- Establishes that if the theorem is true for an arbitrary positive integer k, then it is also true for k + 1.
EX:
- Suppose Amal receives three wishes on day k.
THUS: Amal receives three wishes on day k + 1.

OVERALL: Base case establishes the starting point. The inductive step establishes that the truth of one case carries forward to the next.


2.3) Principle of Mathematical Induction
- If the base case is true for n = 1, and the inductive step is true, then the theorem holds for all positive integers.

- Let S(n) be a statement parameterized by a positive integer n. Then S(n) is true for all positive integers n if:
a) S(1) is true. (base case)
b) For all k ∈ Z^+, S(k) implies S(k + 1). (Inductive Step)

EX:
S(1) AND ∀k ∈ Z^+, S(k) -> S(k + 1)
THUS: ∀n ∈ Z^+, S(n)


2.4) Inductive Hypothesis
- Is the supposition that S(k) is true when carrying out the inductive step.
- The inductive hypothesis is S(k).
- What you must establish is S(k+1).
You are not assuming that the theorem is true for every value of \(n\). You are temporarily assuming it is true for an arbitrary \(k\), 
then demonstrating that this assumption leads to the next case.


2.5) Why Induction Works
a) P(1) is true.
b) For all k >= 1, P(k) implies P(k + 1).
c) When k = 1, P(1) implies P(2), so P(2) is true.
d) When k = 2, P(2) implies P(3), so P(3) is true.
e) This process continues for every positive integer.

THUS: ∀n >=1, P(n) is true.

4. Format of an Inductive Proof
General Proof Structure:
1) State the theorem.
2) Begin the proof by induction on 'n'.
3) Establish the base case.
4) State the inductive hypothesis.
5) Prove the inductive step.
6) Conclude that the theorem holds for all applicable positive integers.

EX: Proving a Summation Identify by Induction
THEOREM: For every positive integer 'n',
n
Σ j = n(n+1)/2
j=1

PROOF: By induction on 'n'.

STEP 1: Base Case
- Set: n = 1
- Evaluate the left-hand side:
1
Σ j = 1
j=1

- Evalute the right-hand side:
1(1+1) / 2 = 1
- BOTH Sides equal 1.
THUS: Base case is true.


STEP 2: Inductive Hypothesis
- Suppose that for an arbitrary positive integer 'k',
k
Σ j = k(k+1)/2
j=1
- This is an inductuve hypothesis.
AS you are assuming the theorem holds for n = k.


STEP 3: Inductive Step
- Prove the theorem holds for n = k + 1:
k+1
Σ j = (k+1)(k+2) / 2
j=1

- Evaluate left-hand side:
k+1
Σ j
j=1
- Separate the final term from the summation:
 k
=Σ j + (k + 1)
 j=1

- Apply the inductive hypothesis:
= k(k+1)/2 + (k+1)

- Find the common denominator:
= k(k + 1) + 2(k + 1) / 2

- Factor out k + 1:
= (k + 1)(k + 2) / 2
- Thus is the expression needed for P(k + 1).

THUS:
k+1
Σ j = (k+1)(k+2) / 2
j=1
-The inductive step is TRUE.


STEP 4 - Conclusion
- Since the base case is true and the inductive step is true, the principle of mathematical induction establishes that:
∀n ∈ Z^+, n
          Σ j = n(n+1)/2
          j=1

5. Proving Inequalities by Induction
- Mathematical induction can establish inequalities, not just equalities.
- The smallest value of 'n' may not be 1.

EX: 2^n >= 3n
THEOREM: For n >= 4, 2^n >= 3n
- Proof begins at n = 4, because the theorem is only claimed for integers greater than or equal to 4.

5.1) Proving an inequality by Induction
THEOREM: For every integer n >= 4,
2^n >= 3n
PROOF: By induction on 'n'.

STEP 1 - Base Case
SET: n = 4
- Evaluate the left-hand side:
2^4 = 16
- Evaluate the right-hand side:
3(4) = 12

COMPARE: 16 >= 12
RESULT: The inequality is TRUE.
THUS: The base case is established.


STEP 2 - Inductive Hypothesis
- Suppose that for an arbitrary integer k >= 4, 2^k >= 3k
- This is an inductive hypothesis.


STEP 3 - Inductive Step
PROVE: 2^(k+1) >= 3(k+1)

- Start with the left-hand side:
2^(k+1)
- Rewrite the exponent:
= 2 * 2^k
- Apply the inductive hypothesis:
>= 2 * 3k = 6k
- Simplify
= 3k + 3k
- Since k >= 4, we know:
3k >= 3
THUS:
3k + 3k >= 3k + 3
- Factor:
= 3(k + 1)
THUS:
2^(k+1) >= 3(k + 1)
RESULT: The inductive step is established.


STEP 4 - Conclusion
- Since the base case and inductive step are true:
∀n >= 4, 2^n >= 3n


5.2) What Changes when Proving Inequalities?
- The structure remains the same as in inductive proof of an equality:
: Establish the base case.
: Assume the statement for 'k'.
: Prove the statement for 'k+1'.

BUT: Inequalities require careful attention to the conditions that allow you to preserve/establish the inequality.
EX: Proof using: k >= 4, to establish: 3k >= 3
- The additional condition is essential to completing the inductive step.

9.2.1) Why Induction Works
- Understanding how the base case and inductive step establish the truth of a statement for all positive integers.

CONDITIONS: P(1) is true
∀k >= 1, P(k) => P(k + 1)

Inductive step	Result
k=1	              P(1) -> P(2)

k=4	              P(4) -> P(5)

RESULT: The statement is true for every positive integer 'n'.
- The base case establishes P(1). The inductive step repeatedly establishes the next statement from the previous one.

- The inductive hypothesis is the statement assumed to be true during the inductive step. The statement to be proven is Q(k+1).

9.2.4) Proving an inequality by Induction
THEOREM: For all integers n >= 4, 2^n >= n^2
- Identify base case, inductive hypothesis, and the use of that hypothesis within an inequality proof.

Q1) What is proven in the base case?
- The theorem begins at n = 4.
- Substitute 4:
2^4 >= 4^2
16 >= 16
RESULT: For n = 4, 2^n >= n^2
- The base case must use the smallest value covered by the theorem.



Q2) What is proven in the inductive step?
- Inductive hypothesis: 2^k >= k^2
PROVE: 2^(k+1) >= (k+1)^2

RESULT: For every k >= 4, if 2^k >= k^2, then 2^(k+1) >= (k+1)^2
- The inductive step assumes the statement for 'k', then establishes it for (k+1).
