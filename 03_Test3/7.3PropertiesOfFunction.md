7.3 - Properties of Functions

OBJ: Determining whether a function is one-to-one, onto, both (bijective), or neither.

GOAL:
- Determine whether a function is one-to-one, onto, both, or neither.
- Use arrow diagrams to identify function properties.
- Compare the sizes of the domain and target to determine which properties are possible.
- Select a function that satisfies a specified property.
- Provide a counterexample to show that a function does not have a particular property.


-------------------------------------------------------------------------------------------------------------------------------


1. Definition and Notations

One-To-One Function (injective)
DEF: A function f : X -> Y is one-to-one or injective if
x_1 != x_2 -> f(x_1) != f(x_2)
for all x_1, x_2 ∈ X.

MEANING: Different inputs must produce different outputs.
RECOGNIZE: The question asks whether distinct inputs can share an output.
CHECK: Look for two different domain elements mapping to the same target element.
CONCLUDE: If such a pair exists, the function is not one-to-one.



Onto Function (surjective)
DEF: A function f : X -> Y is onto or surjective if its range equals its target:
Range(f) = Y

MEANING: Every target element must be the output of at least one domain element.
RECOGNIZE: The question asks whether every target element is reached.
CHECK: Look for target elements with no incoming arrows, or determine whether every target value has a preimage.
CONCLUDE: If even one target element is never reached, the function is not onto.



Bijective Function (bijection)
DEF: A function is bijective if it is both one-to-one and onto.
Bijective = Injective + Surjective

NOTE: Is a one-to-one correspondence.
RECOGNIZE: To prove that a function is bijective, establish both properties. Showing only one is insufficient.

2. Participation Activity 7.3.1 - One-to-one and onto functions
ASKS: f : X -> A
X = {w,x,y,z},      A = {a,b,c,d}

RECOGNIZE: one-to-one and onto properties from an arrow diagram.
APPROACH:
1) Check whether any two domain elements map to the same target element.
2) Check whether every target element receives an arrow.
3) Classify the function based on both checks.

- One to one?
Yes, every domain element has a distinct output.
- Onto?
Yes, every target element receives an arrow.

RESULT: The function is both one-to-one and onto, so it is bijective.

3. Participation Activity 7.3.2 - Idenfitying one-to-one and onto functions.

Q1) h : Z -> Z, h(x) = x - 4

GIVEN: The function subtracts 4 from every integer.
REQUIRED: Determine whether it is one-to-one, onto, both, or neither.

APPROACH:
Step 1: One-to-One
Supose: h(x_1) = h(x_2)
Then: x_1 - 4 = x_2 - 4
THUS: x_1 = x_2
- So h is one-to-one.

Step 2: Onto
- Let y ∈ Z be any target integer.
x = y + 4
- Since y is an integer, x is also an integer, thus:
h(y + 4) = (y + 4) - 4 = y.
- Every target integer is reached.

RESULT: Both one-to-one and onto (bijective).
