7.3 - Properties of Functions

OBJ: Determining whether a function is one-to-one, onto, both (bijective), or neither.

GOAL:
- Determine whether a function is one-to-one, onto, both, or neither.
- Use arrow diagrams to identify function properties.
- Compare the sizes of the domain and target to determine which properties are possible.
- Select a function that satisfies a specified property.
- Provide a counterexample to show that a function does not have a particular property.


-------------------------------------------------------------------------------------------------------------------------------


1. Definition and Notations

One-To-One Function (injective)
DEF: A function f : X -> Y is one-to-one or injective if
x_1 != x_2 -> f(x_1) != f(x_2)
for all x_1, x_2 ∈ X.

MEANING: Different inputs must produce different outputs.
RECOGNIZE: The question asks whether distinct inputs can share an output.
CHECK: Look for two different domain elements mapping to the same target element.
CONCLUDE: If such a pair exists, the function is not one-to-one.



Onto Function (surjective)
DEF: A function f : X -> Y is onto or surjective if its range equals its target:
Range(f) = Y

MEANING: Every target element must be the output of at least one domain element.
RECOGNIZE: The question asks whether every target element is reached.
CHECK: Look for target elements with no incoming arrows, or determine whether every target value has a preimage.
CONCLUDE: If even one target element is never reached, the function is not onto.



Bijective Function (bijection)
DEF: A function is bijective if it is both one-to-one and onto.
Bijective = Injective + Surjective

NOTE: Is a one-to-one correspondence.
RECOGNIZE: To prove that a function is bijective, establish both properties. Showing only one is insufficient.

Yes, every domain element has a distinct output.

3. Participation Activity 7.3.2 - Idenfitying one-to-one and onto functions.

Q1) h : Z -> Z, h(x) = x - 4

GIVEN: The function subtracts 4 from every integer.
REQUIRED: Determine whether it is one-to-one, onto, both, or neither.

APPROACH:
Step 1: One-to-One
Supose: h(x_1) = h(x_2)
Then: x_1 - 4 = x_2 - 4
THUS: x_1 = x_2
- So h is one-to-one.

Step 2: Onto
- Let y ∈ Z be any target integer.
x = y + 4
- Since y is an integer, x is also an integer, thus:
h(y + 4) = (y + 4) - 4 = y.
- Every target integer is reached.

RESULT: Both one-to-one and onto (bijective).


Q2) t : Z -> Z, t(x) = 2x

GIVEN: The function doubles every integer.
REQUIRED: Determine its one-to-one and onto properties.

APPROACH:
Step 1: One-to-one
Suppose: t(x_1) = t(x_2)
Then: 2x_1 = 2x_2  ->  x_1 = x_2
THUS: t is one-to-one

Step 2: Onto
- Every output of t is an even integer. However, the target contains odd integers, such as 1.
- There is no integer x satisfying: 2x = 1,
- Since x = 1/2 is not an integer
RESULT: One-to-one but not onto.


Q3) f : Z -> Z, f(x) = ⌊(x + 1) / x⌋

GIVEN: The function divides x + 1 by 2 and takes the floor.
REQUIRED: Determine whether it is one-to-one, onto, both, or neither.

Step 1: Check one-to-one
Evaulate two different inputs
- f(0) = ⌊1/2⌋ = 0
- f(1) = ⌊2/2⌋ = 1

- f(2) = ⌊3/2⌋ = 1
- f(1) = 1
Since 1 != 2 but f(1) = f(2), the function is not one-to-one..

Step 2: Check onto
- Let y ∈ Z be any target integer. Choose x = 2y
f(2y) = ⌊(2y + 1) / 2⌋ = ⌊y + 1/2⌋ = y
- Every integer is reached.

RESULT: Onto but not one-to-one.

4. Relative sizes of the domain and target

Cardinality - The number of elements in a finite set.
|D| = number of elements of D.


Property 1: Onto Functions
- If f : D -> T is onto, then every target element must be reached by at least one domain element.
: |D| >= |T|


Property 2: One-to-One functions
- If f : D -> T is one-to-one, then each domain element must map to a distinct target element.
: |D| <= |T|

NOTE: If the domain has more elements than the target, a one-to-one function is impossible.


Property 3: Bijective functions.
- A bijection must be both one-to-one and onto.
: |D| <= |T| and |D| >= |T|
: |D| = |T|

5. Participation Activity 7.3.3 — Properties of functions and relative sizes

ASKS: A function f with domain {0,1}^3 and target {0,1}^2, and whether it is possible for f to be:
1) One-to-one
2) Onto
3) Bijective

NOTE: The notation {0,1}^n represents all binary strings of length n.
THUS: Two choices 0 or 1, so |{0,1}^n| = 2^n

DOMAIN: |{0,1}^3| = 2^3 = 8
TARGET: |{0,1}^2| = 2^2 = 4

Q1) Is it possible for f to be one-to-one?
APPORACH: A one-to-one function requires the domain to have no more elements than the target.
|D| <= |T|
BUT: 8 <= 4
- There are eight inputs but only four possible outputs. At least two inputs must share an output.
RESULT: No

Q2) Is it possible for f to be onto?
APPROACH: |D| >= |T|
: 8 >= 4
- The domain has enough elements to reach all four target elements.
RESULT: Yes

Q3) Is it possible for f to be bijective?
APPROACH: |D| = |T|
BUT: 8 != 4
RESULT: No
