3. The Product Rule (AND logic)
- When an outcome consists of multiple choices that must be made together.
EX: Breakfast special requires a drink, main dish, and a side.
- Each is one part of the final combination.


3.1) Theorem 10.1.1 - The Product Rule
- Let A_1, A_2, ..., A_n be finite sets
THUS: |A_1 * A_2 * ... * A_n| = |A_1| * |A_2| ... |A_n|
STATES: The number of possible combinations is the product of the number of choices available in each category.


3.2) Caterisan Products
NOTATION: A_1 * A_2
- The Cartesian product of two sets. Its elements are ordered pairs containing one element from each set.
NOTE: Product rule count combination of choice, thus more sets can be included as a new category to be considered.


3.3) EX: Counting Breakfast Selections:
- A restaurant offers a breakfast special containing one drink, one main course, and one side.
CHOICES:
- Drinks: D = {coffee, orange juice}
- Main course: M = {pancakes, eggs}
- Sides: S = {bacon, sausage, hash browns}

SELECTION as Ordered TRIPLE sets:
(drink, main course, side)
EX: (coffe, pancakes, bacon)

PRODUCT RULE:
|D * M * S| = |D| * |M| * |S|
= 2 * 2 * 3 = 12 possible combinations of these triple sets.

5. Couting Strings
"String" - A sequence of characters taken from a specified set called an alphabet.

NOTATION:
• ∑ - A set of characters.
• ∑^n - The set of all strings of length 'n' over the alphabet ∑.
• |∑| - The number of characters in the alphabet.


EX:
∑ = {0,1}
- A binary string with a sequence of only 0s and 1s.
THUS: Binary strings of length 6 would be like: 011101, 000111, 111111.


5.1) Counting all Strings of a Given Length
- Product rule to Count string.
- If an alphabet contains 'n' possible characters, then each position in a string has 'n' possible choices.

EX: Binary Alphabet
∑ = {0,1}
- Two choices for each position.
THUS: The number of binary strings of length 6 is:
|∑^6| = 2^6 = 64


5.2) Why the exponent represents string length
CONSIDER: A four-character binary string:
_ _ _ _

EACH: Position can contain either 0 or 1.
2 * 2 * 2 * 2 = 2^4 = 16


5.3) Counting Strings with Restrictions
- A five-but string has the structure:
0 _ _ _ 0
- First and last positions are already determined.
THUS:
|∑| = 1 * 2 * 2 * 2 * 1 = 8

7. The Sum Rule (OR logic)
- Applies when there a multiple possible categories, but only one selection is made.


7.1) When to use the Sum Rule.
- Suppose a customer is choosing only a drink.
- The available drink choices are divided into two categories:
• Hot Drinks: H = {coffe, hot cocoa, tea}
• Cold Drinks: C = {milk, orange juice}

- The customer chooses one drink either hot or cold.
BECAUSE: A drink cannot simultaneously be categorized as both hot and hold, the categories are disjoint.

THUS: |C ∩ H | = 0
TOTAL: Number of choices: 3 + 2 = 5


7.2) The Sum Rule
CONSDIER: 'n' finite sets:
A_1, A_2, ..., A_n

- If the sets are pairwise disjoint:
A_1 ∩ A_j = {empty set} for i != j

THUS: |A_1 U A_2 U ... U A_n| = |A_1| + |A_2| + ... + |A_n|

- The number of elements in a union of mutually exclusive sets is the sum of the number of elements in each set.


7.3) Pairwise disjoint sets
- Two sets are disjoint when they share no elements.

EX:
A = {1,2,3}
B = {4,5}
- No common elements.
THUS: A ∩ B = ∅
RESULT: |A U B| = |A| + |B| = 3 + 2 = 5

8. Participation Activity 10.1.5 - Applying the Sum and Product Rule in Combination: Counting Sets of Bit Strings
"bit string" - Is a sequence consisting only of 0s and 1s.
EX: 0101 is a bit string of length four.

Q1) How many six-bit strings begin and end with a 1, or start with 00?
- Combines two conditions using the word "or".

MUST count:
- Six-bit strings that begin and end with 1.
- Six-bit strings that begin with 00.

BOTH: Categories are disjoint as a string cannot begin with both 1 and 0.
THUS: We can use the sum rule.


CASE 1: Begin and end with 1
- String forms:
1 _ _ _ _ 1

- Four unrestricted positions with two options:
RESULT: 2^4 = 16


CASE 2: Begin with 00
- String forms:
0 0 _ _ _ _

- Four unrestricted positions with two options:
RESULT: 2^4 = 16


COMBINE: Using the sum rule:
RESULT: 16 + 16 = 32



Q2) How many bit strings of length 5 or 6 start with a 1?
ASKS: For strings of either length 5 or 6.
- Is a sum-rule problem as the two possible lengths are mutually exclusive.


CASE 1: Length five, starting with 1:
1 _ _ _ _

- Four unrestricted positions with two options:
RESULT: 2^4 = 16


CASE 2: Length six, start with 1:
1 _ _ _ _ _

- Five unrestricted positions with two options:
RESULT: 2^5 = 32


COMBINE: Using the sum rule:
RESULT: 16 + 32 = 48
