2. Divisibility Proof Induction

2.1) Understanding Divisibility
- A quantity is "even divisible by 3" if it can be expressed as: 3 * m
- For some integer 'm'.

- More generally, an integer 'a' is divisible by an integer 'b' if there exists an integer 'm' such that: a = bm
EX: 63 = 3 * 21
THUS: 63, is evenly divisible by 3.


2.2) Defining a Divisibility Predicate:
PREDICATE: Q(n): 3 evenly divides 2^(2n) - 1
CONSIDER: n = 3:
: 2^(2(3)) - 1
: 2^6 - 1
: 64 - 1 = 63

SINCE: 63 = 3 * 21
- The expression is evenly divisible by 3.
RESULT: Q(3) is true.


2.3) Example: Proving Divisibility by Induction
THEOREM: For every positive integer 'n', 3 evenly divides: 2^(2n) - 1
PROOF: By induction on n.

STEP 1 - Base Case
SET: n = 1
EVAULATE: 2^(2(1)) - 1 = 2^2 - 1
= 4 - 1 = 3
SINCE: 3 is evenly divisible by 3, the theorem holds for n = 1.


STEP 2 - Inductive Hypothesis
SUPPOSE: That for an arbitrary positive integer 'k', 3 evenly divides: 
2^(2(k)) - 1

- By definition of divisibility, this means: 
2^(2(k)) - 1 = 3m, for some integer 'm'.
REARRANGE: 2^(2(k)) = 3m + 1


STEP 3 - Inductive Step
- We must prove that 3 evenly divides:
2^(2(k+1)) - 1

- Simplify the exponent:
= 2^(2k+2) - 1

REWRITE:
= 4 * 2^(2k) - 1

- Apply the inductive hypothesis (from end of STEP 2, SUB 2^(2k) = 3m + 1):
= 4(3m + 1) - 1

- Distribute:
= 12m + 4 - 1
= 12m + 3

- Factor out 3:
= 3(4m + 1)
- Since 'm' is an integer, 4m+1 is also an integer.
THUS: The expression is 3 times an integer, thus it is evenly divisible by 3.


STEP 4 - Conclusion
- Since base case is true and the inductive step is established:
∀n ∈ Z^+,  3 | (2^(2n) - 1)


2.4) Technique: Converting divisibility into an equation.
- If the inductive hypothesis states:
3 | (2^(2k) - 1)
- Then you can express it as:
2^(2k) - 1 = 3m, for some integer 'm'.

3. Using Induction to Prove an Assertion About a Recurrence Relation
- A recurrence relation defines a sequence using:
1) Initial value.
2) A rule that calculates subsequent terms from previous terms.


3.1) Recurrence Relation Versus Explicit Formula
CONSIDER: The sequence
g_0 = 1
g_n = 3_g_(n-1) + 2n, n >= 1
- This is the recurrence definition.

- Can be explicitily represented:
g_n = (5/2) * 3^(n) - n - (3/2), for every n >= 0.


NOTE: Recurrence relation indicates how you can calculate the next term using a previous term.
- Explicit formula allows you to calculate a term directly from its index.


3.2) Understanding the index change
- Recurrence relation initial:
g_n = 3_g_(n-1) + 2n, n >= 1

- However, during the inductive step, we assume the explicit formula is true for g_k and prove it for g_k+1.
THUS: recurrence relation expressed using 'k':
g_k+1 = 3_g_k + 2(k+1), for k >= 0
- Replace n with k + 1.

EQUIVALENT:
g_n = 3_g_(n-1) + 2n, n >= 1
AND
g_k+1 = 3_g_k + 2(k+1), for k >= 0



3.3) Example: Proving the Explicit Formula by Induction
THEROEM: Define the sequence {g_n} as:
g_0 = 1
g_n = 3_g_(n-1) + 2n, n >= 1

- Then for every n >= 0:
g_n = (5/2) * 3^n - n - (3/2)

PROOF: By induction on n.

STEP 1 - Base Case
SET: n = 0
- We must establish:
g_0 = (5/2) * 3^0 - 0 - (3/2)

- Simplify the right-hand side:
= (5/2) * 1 - (3/2)
= (5/2) - (3/2) = 1

- Initial condition states: g_0 = 1
THUS: The theorem holds for n = 0.


STEP 2 - Inductive Hypothesis
SUPPOSE: That for an arbitrary integer k >= 0:
g_k = (5/2) * 3^k - k - (3/2)
- This is the inductive step.


STEP 3 - Inductive Step
PROVE: g_(k+1) = (5/2) * 3^(k+1) - (k+1) - (3/2)

- Start with the recurrence relation:
g_(k+1) = 3_g_k + 2(k+1)

SUB: The inductive hypothesis (From step 2):
= 3(5/2 * 3^k - k - 3/2) + 2(k + 1)

- Distribute:
= 15/2 * 3^k - 3k - 9/2 + 2k + 2

- Combine like terms:
= 15/2 * 3^k - k - 5/2

- Rewrite the exponential term:
= 5/2 * 3 * 3^k - k - 5/2
= 5/2 * 3^(k+1) - k - 5/2
= 5/2 * 3^(k+1) - (k + 1) - 3/2

RESULT: g_(k+1) = 5/2 * 3^(k+1) - (k + 1) - 3/2


STEP 4 - Conclusion
- The base case and inductive step are established.
THUS: ∀n >= 0, g_n = 5/2 * 3^(k+1) - (k + 1) - 3/2

5. Inductive Proofs Showing Closed Forms for Sums of Arithmetic and Geometric Sequences
Closed Form - An expression that calculates the value of a sum directly, rather than requiring you to expand and add every term individually.


5.1) Closed Form for the sum of an arithmetic sequence
THEOREM: Closed form for the sum of terms in an arithmetic sequence

- For any integer n >= 1:
n-1
Σ  (a + jd) = an + (d(n-1)n) / 2
j=0

• a - Represents the first term
• d - Represents the common difference
• n - Represents the number of terms
• j - The summation index

(a + jd) - Terms of an arithmetic sequence
EX:
Index j = 0,    Index j = 1,    Index j = 2,    Index j = 3,    n - 1
Term: a,        Term: a + d,    Term: a + 2d,   Term: a + 3d,   a + (n - 1)d


5.2) Understanding the Formula
SUMMATION:
n-1
Σ  (a + jd)
j=0

EXPANDED:
a + (a + d) + (a + 2d) + ... + (a + (n-1)d)

CLOSED FORM:
an + (d(n-1)n)/2
- an: The initial value 'a' appearing 'n' times.
- Second part is the accumulated common differences.


5.3) Expample: Proving the Arithmetic Sequence Forumla by Induction
THEOREM:
n-1
Σ  (a + jd) = an + (d(n-1)n) / 2, for every integer n >= 1.
j=0

PROOF: By induction on 'n'.

STEP 1 - Base Case
SET: n = 1
SUMMATION:
0
Σ (a + jd)
j=0

- There is only one term, corresponding to j = 0:
= a + 0d
= a

- Evaluate the right-hand side:
a(1) + (d(1-1)1) / 2
= a + 0
= a

- Both sides equal a
THUS: The base case is true.


STEP 2 - Inductive Hypothesis
- Assume that for an arbitrary positive integer 'k':
k-1
Σ  (a + jd) = ak + d(k-1)k / 2
j=0
- This is the inductive hypothesis


STEP 3 - Inductive Step
PROVE:
k
Σ  (a + jd) = a(k + 1) + (dk(k+1)) / 2
j=0

- Start with the left-hand side:
k
Σ  (a + jd)
j=0

- Separate the final term:
             k-1
= (a + kd) + Σ  (a + jd)
             j=0

- Apply the inductive hypothesis:
= (a + kd) + ak + d(k-1)k / 2

- Combine terms:
= a + ak + kd + d(k-1)k / 2

- Group the terms involving 'a':
= a(k + 1) + kd + d(k-1)k / 2

- Find a common denominator for the terms involving 'd':
= a(k + 1) + (2kd + d(k-1)k) / 2

- Factor out 'dk':
= a(k + 1) + dk(2 + k - 1) / 2

- Simplify:
= a(k + 1) + (dk(k + 1)) / 2
- The inductive step is established.


STEP 4 - Conclusion
- Since the base case and inductive step are true:
         n-1
∀n >= 1, Σ  (a + jd) = an + (d(n-1)n) / 2
         j=0



5.4) Technique: Separating the Final Term:
- The inductive hypothesis is:
k-1
Σ  (a + jd) = ak + (d(k-1)k) / 2
j=0

- Next case is:
k
Σ  (a + jd)
j=0

- Separate the last term:
             k-1
= (a + kd) + Σ  (a + jd)
             j=0

- Summation matches the inductive hypothesis.

6) Closed Form for the Sum of a Geometric Sequence

6.1) Understanding the geometric sequence:
- Is a sequence in which each term is obtained by multiplying the previous term by a constant common ratio.

GENERAL TERM: ar^j
• a - The initial term
• r - The common ratio
• j - The summation index

EX: The sequence begins:
a, ar, ar^2, ar^3, ...


6.2) THEROEM 9.3.4 - Closed Form for the Sum of Terms in a Geometric sequence
- For an real number r != 1 and any integer n >= 1:
n-1
Σ  ar^j = (a(r^n - 1)) / r - 1
j=0


6.3) Example: Understanding the Formula
SUPPOSE: a = 2, r = 3, n = 4
- The first four terms are:
2, 6, 18, 54

- Their sum:
2 + 6 + 18 + 54 = 80

- Using the closed-form formula:
(2(3^4 - 1)) / (3-1)
= 2(81 - 1) / 2
= 160 / 2 = 80

- Both methods creates the same result.


6.4) Proving the Geometric Sequence Formula by induction
THEOREM:
n-1
Σ  ar^j = a(r^n - 1) / r - 1, for r != 1 and n >= 1.
j=0

PROOF: By induction on 'n'.

STEP 1 - Base Case
SET: n = 1
SUMMATION:
0
Σ  ar^j
j=0

- Only one term results:
= a

- Evaluate the right-hand side:
(a(r^1 - 1)) / r - 1
= (a(r-1)) / r - 1

- Since r != 1 (r-1 gets cancelled out):
= a

- Both sides are equal.
THUS: The base case is true.


STEP 2 - Inductive Hypothsis
- Assume that for an arbitrary positive integer 'k':
k-1
Σ  ar^j = a(r^k - 1) / r - 1
j=0


STEP 3 - Inductive Step
PROVE:
k
Σ  ar^j = a(r^(k+1) - 1) / r - 1
j=0

- Left-hand side:
k
Σ  ar^j
j=0

- Separate the final term:
         k-1
= ar^k + Σ  ar^j
         j=0

- Apply the inductive hypothesis:
= ar^k + a(r^k - 1) / r - 1

- Find a common denominator:
= (ar^k (r - 1) + a(r^k - 1)) / r - 1

- Distribute:
= ar^(k+1) - ar^k + ar^k - a / r - 1

- Cancel the opposite terms:
= ar^(k+1) - a / r - 1

- Factor out 'a':
= a(r^(k+1) - 1) / r - 1

THUS:
k
Σ  ar^j = a(r^(k+1) - 1) / r - 1
j=0
- The inductive step is established.


STEP 4 - Conclusion
- Since the base case and inductive step are true:
         n-1
∀n >= 1, Σ  ar^j = (a(r^n - 1)) / r - 1, for r != 1.
         j=0

8. An Inductive Proof for Set Operations

8.1) De Morgan's Law for Sets
- Describes a relationship between complements, intersections, and unions.
For two sets:
___________   ___   ___
A_1 ∩ A_2 = A_1 U A_2

- The complement of the intersection(AND) of two sets equal the union(OR) of their complements.


8.2) Generalized De Morgan's Law
_____________________   ___   ___         ___
A_1 ∩ A_2 ∩ ... ∩ A_n = A_1 U A_2 U ... U A_n
- The complement of the intersection of any number of sets is equal to the union of their individual complements.


8.3) Understanding the Induction Strategy
STEP 1: Base Case: n = 2

Theorem becomes:
_________   ___   ___
A_1 ∩ A_2 = A_1 U A_2
- The standard De Morgan's law for two sets.


STEP 2: Inductive Hypothesis:
- Assume the generalized identity holds for 'k' sets:
_____________________   ___   ___         ___
A_1 ∩ A_2 ∩ ... ∩ A_k = A_1 U A_2 U ... U A_k


STEP 3: Inductive Step:
PROVE: Holds for k+1 sets:
_____________________________
A_1 ∩ A_2 ∩ ... ∩ A_k ∩ A_k+1

  ___   ___         ___   _____
= A_1 U A_2 U ... U A_k U A_k+1


8.4) Understanding the Proof
- Define a new set:
B = A_1 ∩ A_2 ∩ ... ∩ A_k

- Expression to prove can be written as:
_________
B ∩ A_k+1

- Apply De Morgan's Law
  _   _____
= B U A_k+1

- Now apply the definition of B:
  _____________________   _______
= A_1 ∩ A_2 ∩ ... ∩ A_k U A_k + 1

- Apply the inductive hypothesis:
   ___   ___         ___    _____
= (A_1 U A_2 U ... U A_k) U A_k+1

- Regroup
  ___   ___         ___   _____
= A_1 U A_2 U ... U A_k U A_k+1
- The exact statement required for k+1 sets.
THUS: Generalized De Morgan's law is established in induction.
