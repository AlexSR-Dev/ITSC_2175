9.1 - Algebra Review

GOALS:
• Apply the fundamental properties of exponents.
• Multiply polynomials using the distributive method or area model.
• Add and subtract rational expressions with the same denominator.
• Find the least common denominator (LCD) when rational expressions have different denominators.
• Simplify algebraic expressions by distributing, combining like terms, and factoring when appropriate.


-------------------------------------------------------------------------------------------------------------------------------


1. Exponents
- Four exponent properties that hold for positive real numbers b an c, and real numbers x and y.

1.1) Property 1: Multiplying Powers with the Same Base
RULE: b^x * b^y = b^(x + y)
- When multiplying powers with the same base, add their exponents.

EX: 2^3 * 2^4 = 2^(3+4) = 2^7

RECOGNIZE: Multiplication between powers with the same base.
THUS: Same base and multiplication → add exponents.


1.2) Property 2: Raising a Power to Another Power
RULE: (b^x)^y = b^(xy)
- When a power is raised to another power, multiply the exponents.

EX: (2^3)^4 = 2^(3*4) = 2^12
THUS: A power raised to a power → multiply exponents.


1.3) Property 3: Dividing Powers with the Same Base
RULE: (b^x) / (b^y) = b^(x-y)
- For nonzero b, dividing powers with the same base means subtracting the denominator's exponent from the numerator's exponent.

EX: 2^5 / 2^2 = 2^3
THUS: Same base and division → subtract exponents, numerator minus denominator.


1.4) Property 4: Raising a Product to a Power
RULE: (bc)^x = b^x * c^x
- When a product is raised to a power, the exponent applies each factor.

EX: (2 * 3)^2 = 2^2 * 3^2
THUS: A product raised to a power → apply the exponent to every factor.

2. Polynimal Arithmetic
- Two methods for multiplying polynomials:

2.1) The Distributive Method
- That multiplication distributes across addition and subtraction.

EX: a(b + c) = ab + ac
OR: (x + 2)(x + 3) = x^2 + 5x + 6


2.2) The Area Model
- Organizes multiplication in a grid. Each row represents a term from one polynomial and each column represents a term from the other
polynimal. The cells contain the products of those terms.

EX: (x + 2)(x + 3), the grid:
| X | x   | 3  |
|---|---: |---:|
| x | x^2 | 3x |
| 2 | 2x  | 6  |

THUS: x^2 + 3x + 2x + 6 = x^2 + 5x + 6

3. Adding and Subtracting Rational Expressions
- Is a quotient of polynomials:
x^2 / x + 5


3.1) Adding or Subtracting Rational Expressions with the Same Denominator
RULE: When rational expressions have the same denominator, add or subtract their numerators and retain the common denominator.

ADDITION:
a/c + b/c = (a + b) / c

SUBTRACTION:
a/c - b/c = (a-b) / c
WHERE c != 0 for BOTH.


EX:
x^2/(x + 5) - (7x-10)/x+5

STEP 1: Keep the denominator:
(x^2 - (7x - 10)) / x + 5

STEP 2: Distribute the negative sign:
(x^2 - 7x + 10) / x + 5


3.2) Adding or Subtracting Rational Expressions with Different Denominators
- You must first find a least common denominator (LCD).

EX:
6/(x^2 - 4) + 2/(x^2 - 5x + 6)

- The denominators are: x^2 - 4 AND x^2 - 5x + 6.
STEP 1: Factor the denominator of each Fraction:
(x^2 - 4) = (x + 2)(x - 2)
(x^2 -5x + 6) = (x - 2)(x - 3)
THUS:
6 / (x+2)(x-2) + 2 / (x-2)(x-3)

STEP 2: Find the LCD
- The shared factor (x-2) appears once.
LCD = (x+2)(x-2)(x-3)

STEP 3: Find the New Numerator for Each Fraction
- The first fraction is missing (x-3), thus multiply its numerator and denominator by (x-3):
6/(x+2)(x-2) = 6(x-3) / (x+2)(x-2)(x-3)

- The second fraction is missing (x+2) in its denominator, thus multiply its numerator and denominator by (x+2):
2/(x-2)(x-3) = 2(x+2)/ (x+2)(x-2)(x-3)

STEP 4: Combine the Fractions
- Since both have the same denominator:
6(x-3) + 2(x+2) / (x+2)(x-2)(x-3)

STEP 5: Distribute and Combine Like Terms
6(x-3) = 6x - 18
2(x+2) = 2x + 4

THUS: 6x - 18 + 2x + 4 / (x+2)(x-2)(x-3)
RESULT: 8x - 14 / (x+2)(x-2)(x-3)
