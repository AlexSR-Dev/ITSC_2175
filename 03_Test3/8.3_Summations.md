1. Summation Notation: Fundamentals
- Express the sum of terms in a numerical sequence using the Greek capital letter sigma, Σ.

CONSIDER: The term a_s, a_(s+1),...,a_t
SUM: Written as 
t
Σ a_i = a_s + a_(s+1) + ... + a_t
i=s


DEFS & NOTATIONS:
Σ - Summation symbol meaning to add terms.
i - The index of summation; a placeholder for each term's index.
s - The lower limit of summation.
t - The upper limit of summation.

a_i - The summand: the expression being evaluated and added.

t
Σ   a_i - The sum of terms obtained for every integer i from s through t, inclusive.
i=s

Summation Form - Compact expression using Σ.
Expanded Form - Sum written out term by term.

4) Pulling out the final term from a summation
IDENTIFY:
n        n-1
Σ a_j  = Σ  a_j + a_n
j=m      j=m

When n > m.

THUS: Separate the last term of a summation, leaving a new summation whose upper limit is one less than before.
- Original upper limit: n
- New upper limit: n - 1
- Removed term: a_n

EX:
CONSIDER:
n
Σ (j + 1)^2
j=1

EXPAND:
(1 + 1)^2 + (2 + 1)^2 + ... + (n + 1)^2
=
n-1
 Σ (j+1)^2 + (n + 1)^2
j=1

THUS:
n               n-1
Σ (j + 1)^2  =  Σ  (j + 1)^2 + (n + 1)^2
j=1             j=1

WHY: The new limit is n-1, since the original sum includes the terms indexed 1,2,...,n.
- Once the term at index n is removed, the remaining terms stop at n - 1.

6) Change of Variables in Summations
- You must consistently change:
1. The lower limit
2. The upper limit
3. The index variable inside the summand.

ELSE: The value of the sum changes.

EX:
CONSIDER:
n
Σ (j+2)^3
j=1

LET: i = j + 2
- To express the summation in terms of i, determine the new limits.

STEP 1: Find the new lower limit
- When j = 1:
i = 1 + 2 = 3

STEP 2: Find the new upper limit
- When j = n:
i = n + 2

STEP 3: Rewrite the summand
- Since i = j + 2, we have (j + 2)^3 = i^3

THUS:
n               n+2
Σ (j+2)^3   =   Σ   i^3
j=1             i=3

WHY:
- The original sum expands to: 3^3 + 4^3 + ... + (n + 2)^3
- The rewritten sum contains exactly those same terms. Only the index variable and its limits have changed.
NOTE: The rewritten implemented the summand and reflected the changes with the limits.

GENERAL SUB PATTERN:
SUPPOSE: The original index is j, and you introduce a new index i = j + c, where c is a constant.

THEN:
- Original lower limit j = s becomes i = s + c
- Original upper limit j = t becomes i = t + c
- Replace j in the summand with i - c

EX:
t           t+c
Σ F(j)  =   Σ   F(i-c)
j=s         i=s+c

8) Closed Forms for Sums
- A mathematical expression that gives the value of a sum without requiring summation notation or writing out every term individually.

8.1) Closed form for sum of terms in an arithmetic sequence
- With initial term a, common difference d, and n terms:
n-1
Σ  (a + kd)  =  an + d(n-1)n / 2
k=0

HERE: n >= 1.

DEFS & NOTATIONS:
a - Initial term, at index k = 0.
d - Common difference.
n - Number of terms.
a + kd - General term at index k.
n - 1 - Final index when the sequence starts at 0 and has n terms.

EX:
CALCULATE: 5 + 8 + 11 + 14 + 17 + 20 + 23

STEP 1: Identify the parameters.
- Initial term a = 5.
- Common difference d = 3.
- Number of terms n = 7.

STEP 2: Write the summation form
6
Σ (5 + 3j)
j=0

STEP 3: Apply the closed form.
6
Σ (5 + 3j) = 5(7) + 3(7-1)(7) / 2
j=0

= 35 + 126/2 = 98


ALTERNATIVE:
- For n arithmetic terms, the sum equals the number of terms multipled by the average of the first and last terms:
s_n = n(a_0 + a_(n-1)) / 2

9) Closed form for the sum of terms in geometric sequence
- For any real number r != 1 and any integer n >= 1,
n-1
Σ ar^k  =   a(r^(n) - 1) / r - 1
k=0

DEFS & NOTATIONS:
a - Initial term, at index k = 0.
r - common ratio.
n - Number of terms.
ar^k - General term at index k.
r != 1 - Required condition for this version fo the formula. Also the denominator would be zero otherwise.


EX:
CALULATE: 3 + 6 + 12 + 24 + 48 + 96

STEP 1: Identify the parameters
- Initial term a = 3.
- Common ratio r = 2.
- Number of terms n = 6.

STEP 2: Write the summation form
5
Σ 3 * 2^k
k=0

STEP 3: Apply the closed form
5
Σ 3 * 2^k   =   3(2^(6) - 1) / 2 - 1
k=0

= 3(64-1) / 1 = 3(63) = 189

11) EXAMPLE 8.3.1 - Total Sales of a Company with Exponential Growth
- The source considers a company whose monthly sales are expected to grow by 10%. If it sells a widgets in one month, the next month's sales are 1.1(x).

- The company sells 1,000 widgets in January. The question asks for projected sales over the entire year.

STEP 1: Recognize the Sequence
- The number of widgets sold each month forms a geometric sequence because each month is 1.1 times the previous month's sales.
- Initial term: a = 1000
- Common ratio: r = 1.1
- Number of months: n = 12

STEP 2: Write the sum
- Using January as index k = 0, the total is:
11
Σ 1000(1.1)^k
k=0

STEP 3: Apply the geometric-sum formula
S = 1000((1.1)^12 - 1) / 1.1 - 1
= 21,384
