10.4 - Counting Subsets

OBJ: Counting the number of ways to select a subset of a particular size from a finite set, using combinations and the 'n' choose 'r' formula.

GOALS:
• Calculate the number of ways to select a subset of elements from a given set.
• Distinguish between r-permutations and 'r'-subsets.
• Apply the k-to-1 rule to count subsets.
• Use the n choose r formula to count r-subsets.

2. Difference Between Permutations and Subsets

2.1) Counting Problem
PROVIDES: A class containing 20 students.
- Must elect three representatives for council meeting.

THUS: A vote is conducted to accounce the three students with the most votes, but does not reveal:
- How many votes each student received.
- If one representative received more votes than another.

Q) How many different ways are there to select the three representatives?
NOTE: The outcome is the group of 3 students not a ordered sequence.
THUS: Requires counting subsets, not permutations.


2.2) What is an r-subset?
- Is a subset containing exactly 'r' elements selected from a larger set.
EX: S = {a,b,c}

- The following are 2-subsets:
{a,b}, {a,c}, {b,c}

NOTE: {a,b} = {b,a}, order DOES NOT MATTER.
- Set is defined by its elements, not their arrangements.


2.3) Why subsets are also called combinations
Depends of the counting context:
• Counting sequences and ordered arrangements uses permutations.
• Counting subsets and unordered selections uses combinations.

SET: S = {a,b,c}

Q1) Is {b,a} a 2-permuation or a 2-subset from S?

RESULT: 2-subset.


Q2) Is (b,a) a 2-permutation or a 2-subset from S?
- Parentheses indicates a ordered sequences. (b,a) != (a,b), ORDER MATTERS.

Q3) How many different 2-permutations from S are there?
- Set contains three elements.
- Must select 2 elements and arrange them.

PERMUTATION FORMULA:
P(n,r) = n! / (n-r)!

SUB:
P(3,2) = 3! / (3-2)! = 3! / 1! = 3 * 2 = 6

RESULT: 6 possible 2-permutation from S: (a,b),(a,c),(b,a),(b,c),(c,a),(c,b)


Q4) How many different 2-subsets from S are there?
- There are: {a,b}, {a,c}, {b,c}
RESULT: 3

4. Using the k-to-1 Rule to Count Subsets
- Calculate the num of subsets by starting num of permutations.

4.1) Understanding the color-section example.
SET: C = {blue,green,orange,pink,red}

SUPPOSE: Select a subset containing three colors.
- Since its a subset, ORDER DOES NOT MATTER.
BUT: With permutations, the three same colors can be arrange in different ways.

THUS: 6 permutations corresponds to the same 3-subset:
(orange,blue,pink)
(orange,pink,blue)
(blue,orange,pink)
(blue,pink,orange)
(pink,orange,blue)
(pink,blue,orange)

{orange,blue,prink}


4.2) Count the 3-permutations
- With five available colors:
P(5,3) = 5! / (5-3)! = 5! / 2! = 5 * 4 * 2 = 60 possible 3-permutations.


4.3) Determine how many permutations correspond to each subset
- Every 3-subset can be arranged in: 3! = 3 * 2 * 1 = 6 different orders.
THUS: Each subset corresponds to exactly 6 permutations.


4.4) Apply the k-to-1 rule
- States that if every element in a target set corresponds to exactly 'k' elements in the original set, then:
Number of target elements = Number of original elements / k

EX: Number of 3-subsets = P(5,3) / 3! = 60 / 6 = 10

5. Participation Activity 10.4.3 - Mapping r-Permutations to r-Subsets: A General Rule

5.1) Understanding the Mapping
LET: S = {1,2,...,n}
- Count the number of r-subsets from S.
- The number of r-premutations is: P(n,r)
BUT: Every r-subset can be arranged in: r!
THUS: Each subset corresponds to exactly r! permutations.


5.2) Deriving the general formula
APPLY: The k-to-1 rule with: k = r!
THEN: Number of r-subsets = Number of r-permutations / r!

SUB:
Number of r-subsets = P(n,r) / r!
= 1 / r! * n! / (n-r)!
= n! / r!(n-r)!

- General Forumla for Counting subsets.

7. Definition - Counting Subsets: 'n' Choose 'r' Notation
- The number of ways to select an r-subset from a set of size 'n' is:
(n) = n! / r!(n-r)!
(r)
or
(n r)

READS: "n choose r."

(n) == C(n,r)
(r)

7.1) Formula
n! - Counts the possible ordered selections, including the unused elements in the factorial expansion.
r! - Removes duplicate arrangement of the selected elements.
(n-r)! - Accounts for the elements that were not selected.


7.2) When to use "n choose r"
• You select a specified number of elements from a larger set.
• The order of selection does not matter.
• An element cannot appear more than once in the subset.

8. Participation Activity 10.4.5 - Calculating "n choose r"

Q1) Calculate (7 3) = n! / r!(n - r)!
SUB: (7 3) = 7! / 3!(7-3)!
= 7! / 3!4!

EXPAND AND CANCEL(Out factorials):
= 7 * 6 * 5 * 4! / 3! * 4!
= 7 * 6 * 5  / 3 * 2 * 1
= 210/6 = 35


Q2) Calculate (7 4)
SUB: (7 4) = 7! / 4!(7-4)!

EXPAND AND CANCEL:
= 7 * 6 * 5 * 4! / 4! * 3!
= 7 * 6 * 5 / 3 * 2 * 1
= 35


Q3) Calculate (100 1)
ASKS: The number of ways to select one element from a set containing 100 elements.
(100 1) = 100! / 1!(100-1)!
= 100! / 1! * 99!
= 100 * 99! / 99!
= 100


Q4) Calculate (100 100)
ASKS: The number of ways to select a subset containing all 100 elements.
(100 100) = 100! / 100!(100-100)!
= 100! / 100! * 0!
= 1

NOTE: 0! = 1

9. The Symmetry Property of Combinations
IDENTITY:
(n r) = (n n-r)
MEANS: The number of ways to select 'r' elements from a set of size 'n' is equal to the number
of ways to select the 'n-r' elements left behind.


9.1) Deriving the Identify:
START: (n n-r)

APPLY: Combination formula:
(n n-r) = n! / (n-r)! (n-(n-r))!
= n! / (n-r)!r!
= n! / r!(n-r)!
= (n r)

THUS:
(n n-r) = (n r)


9.2) What does this identify mean?
SUPPOSE: A group contains 10 students and you need to select 3 representatives.
- Selecting three representatives is equivalent to selecting the seven students who are not representatives.

THUS: (10 3) == (10 7)
'bijection' - A one-to-one correspondence between two sets.


9.3) What is an identity?
- An equation that holds for all values for which the expressions are well-defined.

Symmetry Equation: (n r) = (n n-r)
- Is an identity as it holds for every nonnegative integer 'n' and every integer 'r' between 0 and n.


9.4) Why symmetry property is useful
- Simplifies the calculations to choose whichever lower value is smaller.

EX: (100 97) = (100 3)
- Instead of 97, you can calculate (100 3)

10. Participation Activity 10.4.6 - Examples of Counting Subsets

Q1) Selecting members of a math club
ASKS: A teacher must select four members of a math club to participate in an upcoming competition.
- Club conatins 12 members.
Q) How many ways can the teacher select the four members?
STEP 1 - Identify the available and selected elements
n=12, r=4

STEP 2 - Determine whether order matters
- The teacher is selecting a group of 4 students, the order of names does not matter.
THUS: Use combinations

STEP 3 - Apply formula
(12 4) = 12! / 4!(12-4)!
= 12! / 4!8!
= 12 * 11 * 10 * 9 / 4 * 3 * 2 * 1
= 495


Q2) Selecting locations for file replication
- A file will be replicated on three different computers in a distributed network containing 15 computers.
Q) How many ways are there to select the locations for the file?
STEP 1 - Identify the available and selected elements
n=15, r=3

STEP 2 - Determine whether order matters
NOTE: The problem asks which three computers will store the file not the order.
THUS: use combinations

STEP 3 - Apply formula
(15 3) = 15! / 3!(15-3)!
= 15! / 3!12!
= 15 * 14 * 13 / 3 * 2 * 1
= 455

11. Counting Binary Strings with a Fixed Number of 1s
- Applies combination formula to binary strings.
'binary string' - Is a sequence made up of only two possible characters: {0,1}

11.1) Understanding the connection between subsets and binary strings
- Consider a 5-bit binary string that contains exactly two 1s
EX: 11000
- String has 5 positions and two positions contain a 1.
NOTE: Exact positions can change the string.


11.2) Establishing the Correspondence
- Bijection between:
• 5-bit strings containing exactly two 1s
• 2-subsets of the set {1,2,3,4,5}.
- Each 2-subset identifies the positions where the 1s appear.

EX:
SELECT POSITIONS        |       Corresponding Binary String
{1,2}                           11000
{1,3}                           10100
{1,4}                           10010
{1,5}                           10001
{2,3}                           01100
{2,4}                           01010
{2,5}                           01001
{3,4}                           00110
{3,5}                           00101
{4,5}                           00011
- Every 2-subset corresponds to exactly one binary string with two 1s.


11.3) Count the strings
- 5 available positions and select two positions for the 1s.
THUS:
Number of Strings = (5 2)
= 5! / 2!3!
= 5 * 4 / 2
= 10


11.4) General formula for binary strings with exactly 'r' ones
- For a binary string of length 'n' containing exactly 'r' ones:
• There are 'n' available positions.
• Exactly 'r' positions must be selected for the 1s.
• All remaining positions contains 0s.

THUS:
Number of Binary Strings with exactly 'r' ones = (n r)

RECOGNIZE: Wording
• Binary strings of a specified length.
• Exactly a certain number of 1s.
• A fixed number of positions containing 1.
• All other positions must contain 0.
