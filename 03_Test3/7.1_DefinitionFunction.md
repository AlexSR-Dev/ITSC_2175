1. What a function means
- A function maps elements from one set X to elements of another set Y.
EX: f(x) = x^2 maps a number to its square.


DEF:
A function f that maps elements of a set X to elements of a set Y is a subset of X x Y such that, for every x ∈ X,
there is exactlyy one y ∈ Y for which (x,y) ∈ f.

NOTATION:
f : X -> Y

- X is the "domain" of f.
- Y is the "target" of f, also called the "co-domain".
- f(x) = y means that f maps input x to output y.
- (x,y) ∈ f represents the same assignment using an ordered pair.

FAILS if:
1) An input has no output.
2) An input has more than one output.
- Either means the assignment is not a "well-defined function".
NOTE: Multiple inputs may map to the same ouput. (ALLOWED)


Range:
- The output that the function actually produces.
Identified with the target elements that receive at least one assignment.

NOTATION:
Range(f) = {y : (x,y) ∈ f, for some x ∈ X}
- An element belongs to the range if there is at least one input that maps to it.

2. Participation Activity: 7.1.1 - Specifying function with finite domains.
f : X -> A

With sets: X = {w,x,y,z}, A = {a,b,c,d}
And the ordered-pair definition: f = {(w,a),(x,a),(y,d),(z,c)}
NOTE: (Input, Output)

GOAL: A finite-domain function must assign exactly one output to every element of its domain.
APPROACH:
1) List the elements of the domain.
2) Check the first coordinate of each ordered pair.
3) Confirm that every domain element appears exactly once as an input.
4) Identify which target elements occur as outputs.

- Every domain element appears exactly once.
THUS: The assignment is a well-defined function.
DOMAIN: {w,x,y,z}
TARGET: {a,b,c,d}
RANGE: {a,c,d}

3. Participation Activity 7.1.3 - Recognizing Well-Defined Functions from Arrow Diagrams

APPROACH:
1) Inspect every element in the left-hand set.
2) Check whether an arrow leaves that element.
3) Count its outgoing arrows.
4) Ignore whether every target element receives an arrow.

f DOMAIN: {a,b,c,d}
f TARGET: {w,x,y,z}
f RANGE: {w,x,x,y,z}

Q1) Is f a function?
- No, since element 'b' is mapped to two different target elements. (b,w) and (b,y)
THUS: f is not a function.

g DOMAIN: {a,b,c,d}
g TARGET: {w,x,y,z}
g RANGE: {w,x,z,z}

Q2) Is g a function?
- Yes, as each domain element has exactly one outgoing arrow. NOTE: (a,z) and (b,z) is allowed since multiple input can be the same output
THUS: g is a function.

6. Participation Activity 7.1.15 - Recognizing Well-Defined Algebraic Functions
ASK: Whether each expression defines a well-defined function from R to R.

APPROACH:
- For fractions, check whether any real input makes the denominator zero.
- For square roots, check whether the radicand is nonnegative for every permitted input.
- For expressions containing ±, check whether the rule specifies one output or potentially two.

Q1) f(x) = 1 / (x-1)
Step 1: Identify the domain.
- All real numbers.

Step 2: Check the denominator.
x - 1 = 0 -> x = 1
- At x = 1, the expression is undefined.

RESULT: Not well-defined as a function from R to R.


Q2) g(x) = sqrt(x^2 + 2)
Step 1: Check the radicand
- For every real x, x^2 >= 0.
THUS: x^2 + 2 >= 2 > 0

Step 2: Check the output.
- The principal square root gives exactly one real, nonnegative value.
RESULT: Well-Defined.


Q3) h(x) = ±sqrt(x^2 + 2)
Step 1: Check whether the squre root exists.
- Exists for every real input.

Step 2: Check the number of outputs.
- The ± symbol permits both positive and negative.
- Distinct values because: x^2 + 2 > 0
RESULT: Not Well-Defined.
- Since the rule assigns two different outputs to the same input.

8. Participation Activity 7.1.6 - Functions on Sets of Strings
Define f : {0,1}^2 -> {0,1}^3 such that f(x) = 1x.
NOTE: Notation 1x means placing the bit 1 at the beginning of the input string x.

Q1) What is f(01)?
Step 1: Identify the input: 01
Step 2: Apply the rule f(x) = 1x, placing 1 before the input.
THUS: f(01) = 101


Q2) What is the range of f?
Step 1: List the four possible two-bit inputs: {00,01,10,11}.
Step 2: Apply f(x) = 1x to each input.
RESULT: Range(f) = {100,101,110,111}

10. Participation Activity 7.1.7 - Function Equality
ASKS: According to each definition of functions f and g, is it true that f = g?

Q1) 
f: R -> R,      f(x) = x^2 + 1
g: R -> R^+,    g(x) = (x + 1)^2 - 2x

GIVEN: Both functions have domain R, but their targets differ.
OBJ: Determine whether the function satify every requirement for equality.
APPROACH:
Expand and simplify g(x):
g(x) = (x+1)^2 - 2x
= x^2 +2x + 1 - 2x
= x^2 + 1
THUS: The formulas produce the same algebraic expression.
BUT: The targets are different:
- f has target R.
- g has target R^+.

RESUKLT: Not equal.


Q2)
f: R -> R,      f(x) = |x|
g: R -> R,      g(x) = sqrt(x^2)

APPROACH:
- Identify: sqrt(x^2) = |x|
- Principal square root is nonnegative, so it equals to absolute value of x.
THUS: f(x) = g(x)

RESULT: Equal


Q3)
X = {0,1,2}
f: X -> X,      f(x) = (x - 1)^2
g: X -> X,      g(0) = 1, g(1) = 0, g(2) = 1

APPROACH:
- Evaulate f at each domain element.
For x = 0: f(0) = (0 - 1)^2 = 1.
For x = 1: f(1) = (1 - 1)^2 = 0.
For x = 2: f(2) = (2 - 1)^2 = 1.
- Compare the to the given values of g.

RESULT: Equal
