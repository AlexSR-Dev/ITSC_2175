14 - 6.2 Introduction to Binary Relations

1. What is a Binary Relation?
- Expressing the relationship between two sets.
The binary relation between sets A and B is a subset of the Cartesian product: R ⊆ A x B


Binary would be the relation involving two sets.
A and B may or may not be equal.
IF: a ∈ A
AND: b ∈ B
THEN: (a,b) ∈ R
- Meaning that a is related to b.
Written as: aRb


RECOGNIZE:
- When you see: aRb
Reads as "a is related to b"
Then Check:
1) What set does a come from?
2) What set does b come from?
3) What condition defines the relation?
4) Does the ordered pair satisfy that condition?

9. 6.2.4 - Binary Relations on a Set
- A relation can be defined between two sets where: A = B

- When both sets are the same, the relation is called a "binary relation on a set A."
: R ⊆ A x A
- Both elements of every ordered pair come form A.



The relation R is defined on:
: Z^+
WHERE:
: aRb
- if a and r are relatively prime.
Relatively Prime - For two positive integers if, the only positive integer that evenly divides both is 1.

Equivalently: gcd(a,b) = 1, for positive integers.

RECOGNIZE:
When you see: "relatively prime"
THINK: Do they have any common positive divisor other than 1?


1) 8R12
- Check the common divisors
Both are divisible by: 2 and 4.
- They have a common positive divisor greater than 1.
THUS: FALSE


2) 21R20
- Check the common divisors
21 = 3(7)
20 = 2(2)(5)
- No common positive divisor other than 1.
THUS: TRUE


3) There is a number x such that x != 1 and xRx
- Asking for xRx
- The two numbers are the same.

A number is relatively prime to itself only when: x = 1
because any x > 1 divides itself.

Since the question requires: x != 1
THUS: FALSE


4) There is a number x such that xR7
- We need a positive integer relatively prime to 7.
Choose: x = 1.

- Since the only positive divisor of 1 is 1, 1 and 7 are relatively prime.
THUS: TRUE

AND:

| ------------ | ----------------- |

| (1,3)        | 1 -> 3 |
| (2,2)        | 2 -> 2 |
| (2,3)        | 2 -> 3 |
| (3,4)        | 3 -> 4 |
| (4,3)        | 4 -> 3 |

- THUS the correct arrow diagram must contain exactly these six arrows.


2) Compare the Arrow Diagram:
The diagram contains the following errors:
: 3 -> 2
- Instead of (3,4)

Q1)
Which pair is in the arrow diagram but not the original R?
The extra arrow is: 3 -> 2

THUS: (3,2)
BECAUSE: (3,2) ∉ R


Q2)
Which pair is in the original R, but not represented in the arrow diagram?
- Original relation contains: (3,4)
- But the diagram does not show: 3 -> 4

THUS: (3,4)


3) Compare the Matrix
- The rows and columns corresponds to: 1,2,3,4

Correct maxtrix from R:
USE:
: r = first coordinate
: column = second coordinate

Q3)
Which matrix entry is 0 but should be 1?
- Look at the second row.
The relation contains: (2,2)
- Thus row 2, column 2 must contain 1.

- And the matrix currently has 0.
THUS: (2,2)
WHY?
(2,2) ∈ R
- Meaning the corresponding matrix entry must be: 1
