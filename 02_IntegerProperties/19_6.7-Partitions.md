6.7 Partitions

GOALS:
1. Determine whether two sets are disjoint or a collection of sets is pairwise disjoint
2. Determine whether a collection of sets forms a partition of a given set
3. Find a partition for a given set
4. Determine partitions for sets of strings


-------------------------------------------------------------------------------------------------------------------------------



1. Disjoint Sets
- Two sets A and B are disjoint if they have no elements in common.
: A ∩ B = ∅

EX:
A = {1,2,5}
B = {2,4,6}

- There are no common elements, thus: A ∩ B = ∅

C = {1,2,3}, D = {3,4,5}
- There is a common element: C ∩ B = {3}
- Thus, C and D are not disjoint.


-------------------------------------------------------------------------------------------------------------------------------

2. Pairwise Disjoint
- A sequence of sets A1, A2, ..., An is pairwise disjoint if "every pair of distinct sets is disjoint".
: Ai ∩ Aj = ∅

Suppose:
A1 = {1,2}, A2 = {3,4}, A3 = {2,5}

Check the pairs:
Pair        Intersection        Disjoint?
A1, A2      ∅                   Yes
A1, A3      {2}                 No
A2, A3      ∅                   Yes
- A1 and A3 share the element 2, the entire collection is not pairwise disjoint.

3. Paritions of a Nonempty Set
- A parition of a nonempty set A is a collection of nonempty subsets of A such that every element of A belongs to
exaclty one of those subsets.
FOUR Required Conditions:
1. Every subset must be contained in A.
A1 ⊆ A
- Each element of every subset must belong to the original set.

2. Every subset must be nonempty.
Ai != ∅
- No subset in the partition may be empty.

3. The subsets must be pairwise disjoint.
Ai ∩ Aj = ∅ (i != j)
- No element can belong to two different subsets.

4. The subsets must cover the entire original set.
A = A1 U A2 U ... U An
- Every element of A must appear in at least one subset.

4. Participation Activity 6.7.1 - Set Paritions
- Demonstrates how a set can be divided into smaller subsets so that each original element belongs to exactly one subset.

A = {1,2,3,4,5,6} with subsets:
A1 = {1,4,5}
A2 = {2,3}
A3 = {6}

- Step by Step:
1) Containment: Every element of A1 U A2 U A3 belongs to A.
2) Nonempty subsets: Each subset contains at least one element.
3) Pairwise disjointness: No element appears in more than one subset.
4) Complete coverage: A1 U A2 U A3 = {1,2,3,4,5,6} = A

RESULT: A1, A2, A3 form a partition of A.
- As all four requirements are satisfied.
NOTE: If an element appears in two subsets, the collection would fail.


REAL Numbers:
B1 = {x ∈ R : x < 1}
- All real numbers below 1, excluding 1.

B2 = {x ∈ R : x <= x <= 3}
- All real numbers from 1 through 3, inclusive.

B3 = {x ∈ R : x > 3}
- All real numbers above 3, excluding 3.

- Step by Step:
1) Every subset contains only real numbers.
2) Each subset is nonempty.
3) No real number belongs to two subsets. The boundary values 1 and 3 belong only to B2.
4) Every real number falls into one of the three regions.

THUS: B1 U B2 U B3 = R
RESULT: B1, B2, B3 form a partition of R.

5. Participation Activity 6.7.2 - Set Paritions
- For each question, indicate whether the sets form a partition of the universal set.
THUS: Apply the four partition conditions

Q1) Universal set: R
A1 = {x ∈ R : x <= -4}

A2 = {x ∈ R : -4 < x < 4}

A3 = {x ∈ R : x >= 4}

- Step by Step:
1. Containment: Every set consists only of real numbers
2. Nonempty subsets: All three sets contain real numbers.
3. Pairwise disjointness:
- A1 includes -4 and everything below it.
- A2 includes only values between -4 and 4.
- A3 includes 4 and everything above it.
No value belongs to two subsets.
4. Complete coverage: Every real number is either less than or equal to -4, strictly between -4 and -4, or greater than or equal to 4.

THUS: A1 U A2 U A3 = R
RESULT: A1, A2, and A3 form a partition of R.


Q2) Universal set: Z^+
A1 = {x ∈ Z^+ : x is prime}
A2 = {x ∈ Z^+ : x is odd and composite}
A3 = {x ∈ Z^+ : x is even}
A4 = {1}

- Step by Step:
1. Containment: Every listed set contains only positive integers.
2. Nonempty subsets: All four sets are nonempty.
3. Pairwise disjointness: Check whether A1 and A3 overlap.
- The number 2 is prime and also even,
THUS: A1 ∩ A3 != ∅
- The collection is not pairwise disjoint

4. Complete coverage: The sets collectively cover the positive integers, but this does not fix the overlap.

RESULT: A1, A2, A3, and A4 are not pairwise disjoint.


Q3) Universal Set: Z
O = {x ∈ Z : x is odd}
E = {x ∈ Z : x is even}

- Step by Step:
1. Containment: Both sets contain only integers.
2. Nonempty subsets: Both sets are nonempty.
3. Pairwise disjointness: No integer is simultaneously odd and even.
O ∩ E = ∅
4. Complete coverage: Every integer is either odd or even.
O U E = Z

RESULT: O and E form a partition of Z.

Q6) Consider the set A = {0,1}^5 (the set of all 5-bit strings).
Which collection of sets form a partition of A?

A2 = {00x : x ∈ {0,1}^3} - starts with 00
A3 = {01x : x ∈ {0,1}^3} - starts with 01

- Step by Step:
2. No set in the collection is empty.

4. Every 5-bit string must start with either 1 or 0. If it starts with 0, the next bit must be either 0 (making it 00...) or 1 (making it 01...). Therefore, every element of A belongs to exactly one of these sets.

RESULT: A partition.

A4 = {1x : x ∈ {0,1}^4}

- Step by Step:
