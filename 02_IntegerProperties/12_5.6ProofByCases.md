12 - 5.6 Proof By Cases

- How to prove a theorem by dividing the possible situations into cases.

1. Proof by Cases
- Divides the possible values of a variable into different classes.

Instead of proving: ∀x, P(x)
- All at once, divide the possible values of x into cases and prove P(x) separately in each case.

Structure:
Identify all possible cases
->
Prove the theorem in Case 1
->
Prove the theorem in Case 2
->
Continue for all cases
->
All possibilities are covered.

THUS: the theorem is true.


How to recognize when proof by cases is useful?
- Situations in where the variable can naturally be classified.
EX:

Integer
- Every integer is either: even or odd.

Real Number
- A real number can be: x < 0, x = 0, x > 0

Absolute value
- The expression inside an absolute value depends on whether it is: negative or nonnegative

Rationality
- A real number is either: rational or irrational

-------------------------------------------------------------------------------------------------------------------------------

2. What makes a Valid Set of Cases?

Requirement 1 - Every possible value must be included
- Cannot be a value that belongs to none of the cases.

Requirement 2 - Cases may overlap
- Allows situation to belong to more than one case.
EX: x <= 0 and x >= 0 overlap when: x = 0.

NOTE:
- Cases do not have to be mutally exclusive
- They do have to cover the entire domain.

3. 5.6.1 - Proof By Cases
Theroem: "For every integer x, x^2 - x is an even integer."

- The domain is all integers.
The natural cases are:
1) x is even.
2) x is odd.
- These two cases cover every integer.


Case 1: x is even
- By definition: x = 2k
for some integer k

- Substitute 2k for x:
x^2 - x = (2k^2) - 2k
        = 4k^2 - 2k
        = 2(2k^2 - k)

- Since k is an integer:
2k^2 - k is also an integer.

- THUS: x^2 - x is even.


Case 2: x is odd
- By definition: x = 2k + 1
for some integer k

- Substitute 2k for x:
x^2 - x = (2k + 1)^2 - (2k + 1)
        = 4k^2 + 4k + 1 - 2k - 1
        = 4k^2 + 2k
        = 2(2k^2 + k)

- Since k is an integer:
2k^2 + k is an integer

- THUS: x^2 - x is even.


FINAL Conclusion: The two cases cover every integer, and the theorem was proven in both cases.
THUS: "x^2 - x is even for every integer x."

4. 5.6.2 - Dividing a Domain into Separate Cases
- Do the cases cover every possible value in the domain?

1) x is an integer
: Case 1: x < 5
: Case 2: x >= 6

ANSWER: Invalid
WHY?
- The integer: x = 5, belongs to neither cases.


2) x is an integer
: Case 1: x <= 0
: Case 2: x >= 0

ANSWER: Valid
WHY?
- Every integer is either x <= 0 or x >= 0. Overlap at x = 0 is allowed.


3) x is a real number
: Case 1: x < 0
: Case 2: x > 0

ANSWER: Invalid
WHY?
- The value x = 0 is missing.


4) x is a real number
: Case 1: x <= -1
: Case 2: x = 0
: Case 3: x > 1

ANSWER: Invalid
WHY?
- Values such as x = -0.5 and x = 0.5 are not included.


5) x is a real number
: Case 1: x is rational
: Case 2: x is irrational

ANSWER: Valid
WHY?
- Every real number is either rational or irrational.


6) p is a proposition
: Case 1: p is true.
: Case 2: p is false.

ANSWER: Valid
WHY?
- Every proposition is either true or false.

5. Proof by Cases Beyond Numbers

EX: - Six People: Friends and Enemies
Theorem: "In a group of six people, where every pair of people are either friends or enemies, there are three people who are either:"
: all mutual friends, or
: all mutual enemies.


How the Cases are Choosen
- Choose one particular person, x.
- There are five other people, since five is odd, x cannot have the same number of friends and enemies.

THUS, one of these must occur:
Case 1
- x has more friends than enemies.

Case 2
- x has more enemies than friends.


Case 1 - More Friends
- Since x has more friends than enemies among five people, x has at least three friends.
Possibiliy A
- Those three people are all mutual enemies.
Then the theroem is already satisfied.

Possibility B
- They are not all mutual enemies.
Therefore, at least two of them must be friends with each other.
So the two people are both friends with x.
x + two mutual friends, forms three mutual friends.


Case 2 - More enemies
- x must have at least three enemies.
Possibility A
- They are all mutual friends.
Then the theorem holds.

Possibility B
- They are not all mutual friends.
Thus, at least two of them must be enemies with each other.
So, at least two of them must be enemies with each other.
Those two are both enemies of x.
x + two mutual enemies, forms three mutual enemies.


RECOGNIZE:
Choose a natural dividing point
->
Create cases covering all possibilities
->
Solve each case

6. 5.6.3 - Perfect Squares and Multiple of 4
Theorem: "Every perfect square is either a multiple of 4 or a multiple of 4 plus 1."
Perfect square written as: n^2 for some integer n.

Natural Cases:
1) n is even.
2) n is odd.

Case 1: n is even
Q1) What is A?
Even means: n = 2k
ANSWER: A = 2k

Q2) What is B?
Substitute:
n^2 = (2k)^2 = 4k^2
SO: B = 4k^2
- A multiple of 4.


Case 2: n is odd
Q3) What is C?
Odd means: n is odd

Q4) What is D?
For an odd integer: n = 2k + 1

Q5) What is E?
Square:
n^2 = (2k + 1)^2
= 4k^2 + 4k + 1
= 4(k^2 + k) + 1

THUS: E = 4(k^2 + k) + 1
Has the exact target form: multiple of 4 + 1.

7. 5.6.4 - The Square of a Number is Nonnegative
Theorem: "For every real number x: x^2 >= 0"

Case 1: x < 0
- If: x < 0,
multiplying both sides by x reverses the inequality because x is negative: x^2 > 0.
THUS: x^2 >= 0.


Case 2: x = 0
Multiply: x = 0
by x: x^2 = 0
THUS: x^2 >= 0.


Case 3: x > 0
Multiplying: x > 0
by the positive number x keeps the inequality direction: x^2 > 0.
THUS: x^2 >= 0.

The reason for the three cases covers every real number.
NOTE: When multiplying an inequality:
: By a positive number -> direction stays the same.
: By a negative number -> direction reverses.

8. Proof by Cases and Absolute Value
- Absolute value is naturally suited to proof by cases because its definition depends on whether the input is negative or nonnegative.

Definition:
|x| = {x, x < 0}, {x, x >= 0}

EX:
If: x = -3,
Then: |x| = -(-3) = 3.

If: x =3,
Then: |x| = 3.


NOTE: Cases can Overlap
EX:
x + 5 >= 0
AND
x + 5 <= 0
Both include:
x + 5 = 0
Thus allowed.

9. 5.6.2 - Absolute Value
Theorem: "For every real number x: |x + 5| - x > 1"

Case 1:
x + 5 >= 0
THUS:
|x + 5| = x + 5.
SO:
|x + 5| - x = (x + 5) - x
= 5 > 1
- THUS: the theorem holds in Case 1.


Case 2:
x + 5 <= 0
THUS:
|x + 5| = -(x + 5)
SO:
|x + 5| - x = -(x + 5) - x
= -2x -5

FROM: x + 5 <= 0,
Subtract 5: x <= -5
Multiply by -1, reversing the inequality: -x >= 5
Multiply by 2: 2(-x) >= 10
Subtract 5: 2(-x) - 5 > 5
THUS: 2(-x) - 5 > 1
SO: |x + 5| - x > 1

FINAL conclusion: Both Cases establish the theorem: |x + 5| - x > 1

10. 5.6.5 - Absolute Value Cases
Theorem: "For every pair of real numbers x,y: |xy| = |x||y|"

The four cases based on the signs of x and y:
1) x <= 0, y <= 0
2) x <= 0, y >= 0
3) x >= 0, y >= 0
4) x >= 0, y <= 0


Case 1: x <= 0, y <= 0
THEN:
xy >= 0
SO:
|xy| = xy

ALSO:
|x| = -x, |y| = -y
THUS:
|x||y| = (-x)(-y) = xy
SO:
|xy| = |x||y|


Case 2: x <= 0, y >= 0
THEN:
xy <= 0
THUS:
|xy| = -xy

ALSO:
|x| = -x, |y| = y
THUS:
|x||y| = (-x)(y) = -xy
SO:
|xy| = |x||y|


Case 3: x >= 0, y >= 0
THEN:
xy >= 0
THUS:
|xy| = xy

ALSO:
|x| = x, |y| = y
THUS:
|x||y| = xy
- So the theorem holds


Case 4: x >= 0, y <= 0
THEN:
xy <= 0
THUS:
|xy| = -xy

ALSO:
|x| = x, |y| = -y
THUS:
|x||y| = x(-y) = -xy
- Theorem holds

11. 5.6.6 - Ordering an Absolute-Value Proof
For: |xy| = |x||y|, the four cases can be organized in numerical order as:

Case 1
x >= 0, y >= 0

Case 2
x >= 0, y <= 0

Case 3
x <= 0, y >= 0

Case 4
x <= 0, y <= 0

12. Without Loss of Generality
- Abbreviated: WLOG
: Used when two cases are so similar that proving one automatically establishes the other by simply
switching the roles of the variabels.

Instead of writing both cases you can say:
"Without loss of generality, assume..."
and prove only one.


EX - Product of Integers
Theorem: "For any two integers x and y, if x is even or y is even, then: xy is even."

There are two cases:
Case 1:
x is even

Case 2:
y is even

- These proofs are identical.
THUS:
- "Without loss of generality, assume that x is even"

THEN:
x = 2k for some integer k.

THUS:
xy = (2k)y
= 2(ky)
- Since k and y are integers: ky is an integer.

RESULT: xy is even.
- Same argument works whether the roles of x and y were reversed.

13. 5.6.7 - When Can WLOG Be Used?
Q1)
Theorem: "If x and y have the same parity, then 3x and 5y also have the same parity."

Cases:
: x, y both even.
: x, y both odd.

Can WLOG merge these case?
- NO

WHY?
- The two cases aren't simply the same argument with x and y swithced.
- Even and odd cases require different target forms:
EVEN: x = 2k
ODD: x = 2k + 1
- Thus WLOG doesn't eliminate the need for both cases.



Q2)
Theorem: "max(x,y) + min(x + y) = x + y."

Cases:
Case 1
x <= y.

THEN:
min(x,y) = x
AND:
max(x,y) = y.


Case 2
x >= y.

THEN:
min(x,y) = y
AND:
max(x,y) = x

Can WLOG be used?
- YES
- The cases are mirror images, thus switching is the same result.

14) 5.6.1 - WLOG and Parity
Theorem: "if integers x and y have different parity then: x + y is odd."

Using WLOG assumes: x is even and y is odd.

Since x is even: x = 2j for some integer j.
Since y is odd: y = 2k + 1 for some integer k.

Substitute:
x + y = (2k) + (2k + 1)
= 2(j + k) + 1.
- Since j and k are integers: j + k is an integer.

THUS: x + y is odd.

Why WLOG works:
The only other possibility is:
: x odd
: y even.
- The same argument with x and y switched.

15) Proof Contrapositive With Cases
- Combine two proof methods:
: Contrapositive
: Cases

Theorem: "If x is a real number and: x^2 < x, then: 0 < x < 1."

Step 1 - Take the Contrapositive
Original: x^2 < x -> 0 < x < 1.

The conclusion is:
0 < x < 1.
Its negation is:
x <= 0 or x >= 1

THUS the contrapositive is:
x <= 0 or x >= 1 -> x^2 >= x.
Now cases can be created.


1) Case 1
x <= 0

We already know:
x^2 >= 0
AND:
x <= 0

THUS:
x^2 >= 0 >= x
SO:
x^2 >= x


2) Case 2
x >= 1

Since x >= 1, x is positive.
Multiply:
x >= 1 by x.

Because x > 0, the inequality direction stays the same:
x^2 >= x
THUS:
x^2 >= x


3) Conclusion
Both cases prove: x^2 >= x
THUS, the contrapositive is true, so the original theorem is true: x^2 < x -> 0 < x < 1.

RECOGNIZE:
Contrapositive FIRST
Then
Cases SECOND.
