1. Even and Odd Integers

Even Integer - An integer z is even if there is an integer k such that: z = 2k

To prove a number is even:
1. Start with the number.
2. Find an integer k.
3. Show that the number can be written as 2k.
4. State that because k is an integer, the number is even.

EX: Show that -128 is even.
: -128 = 2k
- Divide by 2:
: k = -64
- Since -64 is an integer:
: -128 = 2(-64)
- Thus, -128 is even.




Odd Integer - An integer z is odd if there is an integer k such that: z = 2k + 1

To prove a number is odd:
1. Start with the number.
2. Set it equal to 2k + 1.
3. Solve for k.
4. Verify that k is an integer.
5. Conclude that the number is odd.

EX: Show that -73 is odd.
We want: -73 = 2k + 1
- Subtract 1:
: -74 = 2k
- Divide by 2:
: k = -37
- Since -37 is an integer,
: -73 = 2(-37) + 1
- Thus, -73 is odd




Important Pattern: Expressions Involving n
Can be rewritten into either:
2k
OR
2k + 1

EX: 2n + 3 is it even or odd?
- Rewrite: 2n + 3 == 2n + 2 + 1
- Factor the first two terms: = 2(n + 1) + 1
- Since n is an integer, n + 1 is also an integer.
- Thus the expression forms: 2k + 1
and is odd.


TEST NOTE:
When a expression contains n:
- Try to rewrite it as 2(integer) -> even.
- Try to rewrite it as 2(integer) + 1 -> odd.

2. Parity
- Whether a number is even or odd.

Two numbers have:
- The same parity if they are both even or both odd.
- Opposite parity if one is even and the other is odd.


EX: Do 7 and 22 have the same parity?

For 7: 7 = 2(3) + 1
- Thus, 7 is odd.

For 22: 22 = 2(11)
- Thus, 22 is even.

- One is odd and one is even, thus, they have "opposite parity" so NO they aren't the same parity.



NOTE: 0 is even.
- As 0 = 2(0), since 0 is an integer, it satisfies the definition of an even integer:
2(integer) -> even.

4. Divisibility
- An integer x divides an integer y if and only if:
• x != 0
• y = kx
For some integer k.


Notations: IF
• x | y
- "x divides y."
- y is a multiple of x.
- x is a factor of y.
- x is a divisor of y.

• x ∤ y
- x does not divide y.



Identifying whether x | y
- Can I find an integer k such that y = kx?
If yes -> x|y
if no -> x ∤ y

5. Prime and Composite Numbers

Prime - An integer n is prime if:
1) n > 1, and
2) The only positive number has exactly two positive divisors: 1 and itself.
EX: 2, 3, 5, 7, 11, 13, 17


Composite - An integer n is composite if:
1) n > 1, and
2) There is an integer m such that: 1 < m < n   AND     m | n
- A composite number has a positive divisor other than 1 and itself.
EX: 9, since 3 | 9, and 1 < 3 < 9. Thus 9 is composite.


Numbers that are neither
- The definition requires: n > 1
Thus:
- 0 is neither prime nor composite.
- 1 is neither prime nor composite.

Resulting: FALSE


4. If n is an integer such that n > 1, then n is either prime or composite.

- Since the integer is greather an 1:

6. Inequalities

For "real numbers" x and c, exactly one of these is true:
• x < c
• x = c
• x > c

- Allowing us to reason about the negation of inequalities.

"At least"
- x >= c
Thus, x = c or x > c

"At most"
- x <= c
Thus, x = c or x < c

7. Negating Inequalities

Exactly one of: (x < c), (x = c), or (x > c) is true.

Negation of x < c
- If x < c is not true, then:
 x must either equal c or be greater than c.
THUS, not (x < c) <--> x >= c



Negation of x > c
- If x > c is not true then:
x = c or x < c
THUS, not (x > c) <--> x <= c



Negation Cheat Sheet:

not(x < c) <--> x >= c
not(x > c) <--> x <= c
not(x <= c) <--> x > c
not(x >= c) <--> x < c

10. Conditional Statements with Inequalities
- Has the form: If P, then Q.

- Asks whether each statement is true for every real number x.
- A single counterexample is enough to show that a universal conditional statement is false.


1. if x > 3, then x >= 3

Suppose: x > 3
- If something is greater than 3, it is necessarily greater than or equal to 3.
EX: x = 4
gives: 4 > 3
and: 4 >= 3
Resulting: TRUE.


2. If x <= 4, then x < 4

- False
As the problem is that x <= 4 includes x = 4.
Conuterexample: x = 4
Then: 4 <= 4 is true,
BUT: 4 < 4 is false.
Resulting: FALSE.


3. If x is positive, then x is nonnegative.

Positive means: x > 0
Nonnegative means: x >= 0

Every number greater than 0 is also greater than or equal to 0.
Resulting: TRUE.


4. If x = 3, then x >= 3.

If, x = 3
Then certainly: x >= 3, as allowed by >=
Resulting: TRUE


5. If x < 2, then x <= 1

- True for real numbers.
EX: x = 1.5
Then: 1.5 < 2
BUT: 1.5 <= 1 is false
Resulting: FALSE.


6. If x >= 4, then x > 3

Suppose: x >= 4
The smallest possible of x is 4.
Since: 4 > 3, every number satisfying x >= 4 must also satisfy: x > 3.
Resulting: TRUE.
