10 - 5.4: Proof By Contrapositive

1. Main Idea

A conditional statement has the form:
If p, then c.

A proof by contrapositive proves the logically equivalent statement:
If ¬c, them ¬p

Explanation: "Assume the conclusion is false, then prove that the hypothesis must also be false."


Direct proof: p -> c
Start with: p
and prove: c

Proof by Contrapostive: ¬c -> ¬p
Start with: ¬c
and prove: ¬p

-------------------------------------------------------------------------------------------------------------------------------

2. How to Recognize a Contrapositive
When you see: "If p, then c."

Identify:
| Part       | Meaning                |
| ---------- | ---------------------- |
| p          | Hypothesis             |
| c          | Conclusion             |
| ¬p         | Negation of hypothesis |
| ¬c         | Negation of conclusion |

The Contrapostive is: ¬c -> ¬p

- You negate BOTH parts and reverse their order.

-------------------------------------------------------------------------------------------------------------------------------

3. Why Use a Proof by Contrapositive?
- "Which starting assumption is easier to work with?"

Direct proof
- Start with the hypothesis.

Contrapositive
- Start with the negation of the conclusion.

NOTE: Choose the approach that gives you a more useful expression to work with.

-------------------------------------------------------------------------------------------------------------------------------

4. Example - Even/Odd Integers

Consider: "For every integer x, if x^2 is even, then x is even."

Direct Proof
Assume: "x^2 is even"
Need to Show: "x is even"
- Needs reason backward from the square.


Contrapositive
- Instead, assume the conclusion is false: "x is odd"
THEN: "x = 2k + 1" for some integer k.

- Substitute this directly into x^2:
"x^2 = (2k + 1)^2"
= "2(2k^2 + 2k) + 1"
NOTE: (2k+1)^2 = (2k + 1)(2k + 1) = (4k^2 + 4k + 1) = (4k^2 + 4k) + 1 = 2(2k^2 + 2k) + 1

- This has the form: 2k + 1, so x^2 is odd.
THUS: If x^2 is even, x must be even.

Contrapositive provides: "x is odd" a concrete expression.

5. 5.4.1 - Proof by Contrapositive
Theorem: "If 3n + 7 is an odd integer, then n is even."

Identify the Parts:
Hypothesis: "3n + 7 is odd"

Conclusion: "n is even"

Contrapositive:
- Negate the conclusion: "n is odd"
- Negate the hypothesis: "3n + 7 is even"

THUS: "If n is odd, then 3n + 7 is even."


Step-by-step
1. Assume the negation of the conclusion
"n is odd"

2. Use the definition of odd
"n = 2k + 1", for some integer k.

3. Substitute
"3n + 7 = 3(2k + 1) + 7"

4. Simplify
= 6k + 10
= 2(2k + 5)

5. Match the definition
- Since k is an integer, 3k + 5 is an integer.
THUS: 3n + 7 is twice an integer, so it is even.

Conclusion:
"The contrapositive is true, so the original theorem is true."

Recognition:
"Assume conclusion is false -> convert using a definition -> substitute -> reach negation of hypothesis."

6. 5.4.2 - Fill in the Contrapositive Proof
Theorem: "For every positive integer x, if x^3 is even, then x is even."

Identify the original statement:
Hypothesis: "x^3 is even"

Conclusion: "x is even"

Contrapositive:
Assume: "x is odd"
Prove: "x^3 is odd"


Step-by-step
1. Since x is odd: x = 2k + 1 for some integer k.

2. Substitute:
: x^3 = (2k + 1)^3

3. Expand:
: x^3 = 8k^3 + 12k^2 + 6k + 1

4. Rewrite:
: x^3 = 2(4k^3 + 6k^2 + 3k) + 1

5. Since k is an integer: 4k^3 + 6k^2 + 3k is an integer

THUS: x^3 is odd.
Since: 2(4k^3 + 6k^2 + 3k) + 1, follows the definition of odd: 2k + 1.

NOTE:
1) Identify the contrapositive.
2) Use the definition of odd.
3) Substitute.
4) Rewrite the result in the required odd-number form.

7. 5.4.3 - An Algebraic Theorem
Theorem: "For every real number x, if x^2 + 2x + 1 < 0, then x < 0."

Direct Proof
Start: x^2 + 2k + 1 < 0
Prove: x < 0


Contrapositive:
Conclusion: x < 0
Its negation: x >= 0

Start: x >= 0
Prove: x^2 + 2x + 1 >= 0.


Step-by-step
1. If: x >= 0

2. Then: x^2 >= 0
3. And: 2x >= 0.
4. Also: 1 > 0.

5. Thus: x^2 + 2x + 1 > 0.
- Contradicts the negation of the original hypothesis.

8. When to use Direct Proof vs. Contrapositive
- "Which assumption is easier to work with?"

Direct Proof:
- Use the hypothesis if it gives you a useful expression.

Contrapositive:
- Use the negation of the conclusion if it gives you a useful expression.



Quick Decision Process:
Given: "If p, then c."

Ask:
Question 1: "What would I get from assuming p?"
- If it gives you something easy to manipulate -> direct proof may be useful.

Question 2: "What would I get from assuming ¬c?"
- If that gives you a useful definition/expression -> contrapositive may be easier.

Key IDEA: Choose the starting assumption that makes the proof easier to develop.

9. 5.4.4 Direct vs. Contrapositive
Consider: "For every real number x, if 0 < x < 3, then 15 - 8x + x^2 > 0."

1. Direct Proof Starting Assumption
Hypothesis: 0 < x < 3

2. What is proven?
Conclusion: 15 - 8x + x^2 > 0

3. Contrapositive starting assumption
Conclusion: 15 - 8x + x^2 > 0
Its negation: 15 - 8x + x^2 <= 0

4. What must be proven?
Hypothesis: 0 < x < 3
Its negation: 0 <= x or x >= 3

MUST prove: x <= x or x >= 3

Recognition Rule:
For a compound inequality: "Negate the entire condition, not just one part."

10. De Morgan's law

AND: ¬(A ∧ B) == ¬A V ¬B
- Not both = one or the other is false.


OR: ¬(A V B) == ¬A ∧ ¬B
- Neither = both are false.

-------------------------------------------------------------------------------------------------------------------------------

11. 5.4.5 - De Morgan's Laws and the Contrapositive

Question 1:
"If x < 0 and y > 0, then y < 0"

1) Conclusion: y < 0
2) Negate the conclusion: y >= 0
3) Thus, the contrapositive starts with: y >= 0


Question 2:
- Same theorem asks what must be proven.

Original hypothesis: x < 0 ∧ y > 0
Negate it: x >= 0 V y <= 0

THUS, the contrapositive proves: x >= 0 or y <= 0

BECAUSE: ¬(x < 0 ∧ y > 0)
BECOMES: x >= 0 V y <= 0


Question 3:
Theorem: "If x and y are integers such that xy is even, then x is even or y is even."

1) Conclusion: x is even V y is even.
2) Negate the conclusion:
- Using De Morgan's Law: x is odd ∧ y is odd.
3) Thus, contrapositive starts with: "x is odd and y is odd"


Question 4:
1) Original hypothesis: xy is even
2) Negation: xy is odd
3) Thus, contrapositive proves: xy is odd
- From the assumption that both x and y are odd.

12. Irrational Numbers and Contrapositive Proofs

Definition:
- An irrational number is a real number that is not rational.

THUS for a real number:
- not irrational = rational

Rational numbers have a concrete form: x / y
- Where x, y are integers and: y != 0.

13. 5.4.6 - Irrational Numbers
Theorem: "For every positive real number, if sqrt(r) is irrational, then r is also irrational."

1) Why use contrapositive?
- Direct proof would start with: sqrt(r) is irrational
- "irrational" does not give use a convenient algebraic representaion.

2) Contrapositive gives:
- sqrt(r) is rational.

- Something concrete:
: sqrt(r) = x / y

- For integers x, y, where:
: y != 0


Step-by-step
1) Assume the negation of the conclusion
- Assume r is not irrational, because r is real: r is rational.

2) Use the rational definition
: sqrt(r) = x / y, for integers x, y, y != 0.

3) Square both sides
r = (x / y)^2
r = x^2 / y^2

4) Check the definition
: x^2 is an integer
: y^2 is an integer
: y^2 != 0

THUS: r is rational.

Contrapositive is useful once:
"The original condition gives you an abstract negative property, but its negation gives you a concrete representation."

14. Contrapositive With Multiple Hypotheses

Suppose a theorem has:
(H_1 ∧ H_2) -> C

Means: "If both H_1 and H_2 are true, then C is true."

Contrapositive: ¬C -> ¬(H_1 ∧ H_2)
Using De Morgan's Law: ¬C -> (¬H_1 V ¬H_2)

1) How to prove this?
- You can choose one hypothesis to show false, while assuming:
: The conclusion is false, and
: The other hypothesis remains true.

EX: 
(¬C V H_1) -> ¬H_2
OR
(¬C ∧ H_2) -> ¬H_1

- Show that at least one hypothesis fails.

-------------------------------------------------------------------------------------------------------------------------------

15. Setting up Multiple-Hypothesis Contrapositives
Suppose: "If H_1 and H_2, then C."

1) Step 1, Negate the Conclusion: ¬C

2) Step 2, Keep one hypothesis true.
EX: H_1

3) Step 3, Prove the other hypothesis false:
¬H_2

4) So your proof can begin:
"Assume C is false and H_1 is true. We will show that H_2 is false."
- You can also switch the roles of H_1 and H_2.


Recognition:
- Negate the conclusion and show that at least one hypothesis cannot be true.

16. 5.4.7 - Muliple Hypotheses
Theorem: "If x is rational and y is irrational, then x + y is irrational."

Identify:
: Hypothesis 1: x is rational.
: Hypothesis 2: y is rational.
: Conclusion: x + y is irrational.

1) Contrapositive
Negate the conclusion: x + y is rational
- Now we need to show one of the original hypotheses is false.

Prove: y is rational.
Negation: y is irrational.


Start of Proof:
2) Assume:
: x + y is rational.
: x is rational.

3) Prove:
: y is irrational.


4) Why this setup works?
: If x + y, is rational and 
: x, is rational, then
: y = (x + y) - x
- The proof can then use the properties of rational numbers.

20. Proof Vocabulary - Definitions to Know

1) Integer
- Is a whole number, including negative numbers and zero.
EX: ...,-3,-2,-1,0,1,2,3,...
Not Integers: 1/2, 2.5, sqrt(2)


RECOGNIZE:
Proof says: "Let n be an integer..."



2) Even Integer
- An integer that is even: 2k
- Where k is an integer.

EX:
2 = 2(1)
8 = 2(4)
-6 = 2(-3)

Proof Recognition:
Expression = 2(Integer)
x = 2k

- Means x is even.



3) Odd Integer
- An integer is odd if it can be written as: 2k + 1
- Where k is an integer.

EX:
1 = 2(0) + 1
7 = 2(3) + 1
-3 = 2(-3) + 1

Proof Recognition:
Expression = 2(integer) + 1
x = 2k + 1



4) Rational Number
- Written as: a / b

Where:
: a is an integer
: b is an integer
: b != 0

EX: 1/2, -3/4, 5, 9

Proof Recognition:
integer/nonzero integer
x^2 / y^2
: x^2 is an integer.
: y^2 is an integer.
: y^2 != 0



5) Irrational Number
- A real number that cannot be written as a ratio of two integers with a nonzero denominator.
EX: sqrt(2), pi

For real numbers:
not rational = irrational
AND
not irrational = rational.

Original: IF x is irrational, then..
Contrapositive: Asssume x is not irrational. (x is rational.)

x = a / b



6) Divisibility
Notation: a | b
- Means: a divides b.

Definition is: b = ka, for some integer k.

EX: 3 | 12
Because: 12 = 4(3) and 4 is an integer.

EX: 5 ∤ 12
Because there is no integer k such that: 12 = 5k.


Proof Recognition
Prove: a | b
Target: b = ka, where k is an integer.


- Zero is not positive
- Zero is not negative

- Zero is nonnegative
- Zero is nonpositive

Real Numbers = Rational numbers + Irrational numbers.
