6.9 - Partial Orders

GOALS:
- Draw an arrow diagram for a partially ordered set.
- Determine if a relation is a partial order by analyzing the properties of the relation.
- Determine if two elements in a partially ordered set are comparable or incomparable.
- Find minimal and maximal elements in a partial order.
- Construct an upward drawing (Hasse diagram) to depict the partial order on a finite set.


-------------------------------------------------------------------------------------------------------------------------------


1. Partial order
a ⪯ b
- To express that aRb. The curved symbol distinguishes the partial-order notation from the ordinary <= symbol.
- A set together with a partial order is called a partially ordered set, or poset. Denoted by:
: (A, ⪯)
- Where A is the domain and ⪯ is the partial order defined on it.


1.1) Reflexive
- Every element is related to itself.
a ⪯ a for every a ∈ A

EX: For the relation <= on the integers,
x <= x
- Is true for every integer x.

TO DISPROVE: An element lacking its self-relationship

1.2) Anti-symmetric
- If two elements are related in both directions, they must be equal.
a ⪯ b AND b ⪯ a  ->  a = b

TO DISPROVE: Two distinct elements related both ways

1.3) Transitive
- If a ⪯ b and b ⪯ c, then a ⪯ c
a ⪯ b AND b ⪯ c  ->  a ⪯ c

TO DISPROVE: A two-step chain missing its required endpoint relationship

-------------------------------------------------------------------------------------------------------------------------------

2. EXs of Partial orders

Example A) The relation <= on integers
- (Z, <=) is a partial order.

1) Reflexive: x <= x
2) Anti-symmetric: x <= y AND y <= x  ->  x = y
3) Transitive: x <= y AND y <= z  ->  x <= z

- All three properties hold, so the relation is a partial order.
- A total order, because every pair of integers is comparable.

3. Comparable and Incomparable Elements

3.1) Comparable elements
- Two elements a and b in a partially ordered set are comparable if:
a ⪯ b or b ⪯ a
- At least one of the two relationships must hold.
RECOGNIZE: A question asks whether two elements are comparable.
WHAT TO DO: Check whether either element is related to the other in the partial order.


3.2) Incomparable elements
- Two elements are incomparable if neither relationship holds:
a ⋠ b and b ⋠ a

RECOGNIZE: Neither element can be placed before or after the other under the relation.
EX from the divisibility order: 3 and 5 are incomparable because neither evenly divides the other.


3.3) Total order
- A partial order as a total order if every two elements in the domain are comparable.

Therefore:
- Every total order is a partial order.
- Not every partial order is a total order.

5. Minimal and Maximal Elements

5.1) Minimal Element
- An element x is minimal if there is no distinct element y such that:
y ⪯ x
- Nothing else is strictly below x in the parital order.

5.2) Maximal Element
- An element x is maximal if there is no distinct element y such that:
x ⪯ y
- Nothing else is strictly above x in the partial order.


RECOGNIZE in ARROW DIAGRAM:
- A minimal element has no incoming relationship from a distinct element.
- A maximal element has no outgoing relationship to a distinct element.

NOTE: Self-loops do not disqualify an element from being minimal or maximal.

6. Participation Activity 6.9.3 - Recognizing Partial Orders:
- Whether each described relation is a partial order.

Q1) The domain is a group of brothers and sisters. x ⪯ y if y is at least as old as x. 
All the brothers and sisters have the same mother, so no two of them were born at exactly the same time.

- Relation is defined by: x ⪯ y <--> y is at least old as x.
ASKING: Determine whether the age-based relation satisfies reflexivity, anti-symmetry, and transitivity.
- Step by Step:
1) Reflexivity: Everyone is at least as old as themselves.
age(x) <= age(x) 

2) Anti-symmetry: If x is at least as old as y, and y is at least as old as x, then they have the same age.

3) Transitivity: If y is at least as old as x, and z is at least as old as y, then z is at least as old as x.

RESULT: The relation is a partial order.



Q2) The domain is the set of people working at a company. x ⪯ y if y has a higher salary than x.

- x ⪯ y <--> y has a higher salary than x.
ASKS: Determine whether the strict salary comparison defines a partial order.
- Step by Step:
1) Reflexivity: A person does not have a higher salary than themselves. Thus x ⪯ x us false.

RESULT: No, the relation is not a partial order because it is not reflexive.



Q3) 
The domain is a set of students at a school. x ⪯ y if x has the same birthday as y. At least two students in the school have the same 
birthday.

x ⪯ y <--> x has the same birthday as y.
- NOTE: At least two students share the same birthday.
ASKS: Determine whether sharing a birthday defines a partial order.

- Step by Step:
1) Reflexivity: Every student has the same birthday as themselves. The relation is reflexive.

2) Anti-symmetry: Suppose two distinct students x and y share a birthday. Then both x ⪯ y and y ⪯ x hold, but x != y
- Fails

RESULT: No, the relation is not a partial order because it is not anti-symmetric.
