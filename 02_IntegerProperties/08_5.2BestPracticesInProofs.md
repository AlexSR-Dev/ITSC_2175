08 - Best Practices and Common Error in Proofs

1. Assumptions Allowed in Proofs
- A proof can use facts that are already establihsed or explicitly allowed.

Main Sources:
- Rules of algebra
- Integers are closed under addition, multiplication, and subtraction
- Every integer is even or odd
- There is no integer between consecutive integers
- The relative order of real numbers
- The square of a real number is >= 0
- Every real number is positive, negative, or 0
- Established facts about inequalities

What to ask
- When you see a proof step, ask:
"Can I justify this from an allowed assumption, definition, or previous step?"
- If not, the step is invalid or incomplete.

2. 5.2.1 - Valid Assumptions
- Determine whether each statement is valid.

1) If x is an integer and x > 0, then x > 1.
Test the smallest positive integer: x = 1

Then: 1 > 0, is true
BUT: 1 > 1, is false
THUS: Invalid



2) If x and y are even integers, then x + y is even.
- Even integers can be written:
x = 2a, y = 2b

THEN:
x + y = 2a + 2b = 2(a + b)
Since a + b is an integer, the result is even.
THUS: Valid



3) If x and y are integers, then 3x - y + 4 is an integer.
- Start with integers:
x,y ∈ Z

- Multiplying an integer by 3 gives an integer:
3x ∈ Z

- Subtracting integers remains an integer:
3x - y ∈ Z

- Adding 4 remains an integer:
3x - y + 4 ∈ Z

THUS: Valid



4) If x is a positive real number, then 5 < 2.
- The statement:
5 < 2
is always false, regardless of x.
THUS: Invalid

3. Language Used in Proofs
- Wording of a proof tells the reader why the next statement follows.

Important Keywords:
| Keyword                | Purpose                                         |
| ---------------------- | ----------------------------------------------- |
| **Let**                | Introduces a variable                           |
| **Suppose**            | Introduces a variable or assumption             |
| **Since**              | Gives a reason based on something already known |
| **By definition**      | Uses the definition of a concept                |
| **By assumption**      | Uses an assumption given earlier                |
| **Thus / Therefore**   | Gives a conclusion from previous reasoning      |
| **In other words**     | Restates something more specifically            |
| **gives / yields**     | Indicates an algebraic result                   |
| **We will prove/show** | Tells the reader the goal                       |

MAIN IDEA:
Don't just wrie: x = 2k + 1

Explaing Why:
- "Since x is odd, by defintion x = 2k + 1 for some integer k."
The words establish the logical connection.

4. 5.2.2 - Match Proof Keywords
- The theorem states: "If m and n are integers such that m | n, then m | n^2."

The blanks corresponds to the following:
A) "_ m is nonzero and there exists an integer k such that n = km"
- This comes from the definition of divides
A = By Definition



B) "We will prove that m | n^2. _ we will prove that there is an integer j such that n^2 = jm."
- This restates what must be proven in a more specific way.
B = In other words.



C) "Plugging in n = km into n^2 _ n^2 = (km)^2 = (k^2m)m."
- The substitution gives the next equation.
C = gives



D) "k and m are both integers. _ k^2 * m is also an integer."
- This is a conclusion from the previous fact.
D = Therefore



E) "_ n^2 = jm, where j = k^2 * m is an integer."
- This uses information established earlier.
E = Since

5. Best Practices for Writing Proofs

1) Clearly start and end the proof
Use: "Proof"

2) Use complete sentences
- A proof should read like understandable English with mathematics included.

3) State assumptions
- Tell the reader what the variables represent.

EX: "Let x be an even integer and y be an odd integer."

4) Introduce variables when first used
- Don't suddently use k without explaining where it came from.

5) Explain equation blocks
- Don't simply write several equations.
Introduce them: "Plugging the expression into xy gives: xy = 2k(2j + 1)"

6) Keep algebraic steps understandable.

6. 5.2.3 - Applying Best Practices

The theorem: "The product of an even integer and an odd integer is even."
- Provides progressively improved versions of a proof.

Version #1
Issues:
- No clear Proof beginning/end
- Not written entirely in complete sentences
- x and y are used wihtout first being introduced

WHY?
- The reader should immediately know "What are x and y?" and "Where does the proof begin/end?"



Version #2
"Let x be an even integer and y be an odd integer."
- Assumptions are now established.
HOWEVER, the alegbra is introduced abruptly without explanatory text.

Issues:
- The proof jumps directly into: xy = 2k(2j + 1) = 2(2jk + k)
A better version says:
"Plugging in the expressions for x and y gives: xy = 2k(2j + 1) = 2(2jk + k)"



Version #3
This version fixes the equation introduction:
"Plugging in the expression 2k for x and 2j + 1 for y into xy gives..."
- The remaining issue is the proof's start/end indication.

7. Existential Instantiation

If you know: "There exists and integer with a certain property."
- You can give that integer a name.

EX: "n is odd"
- By definition: n = 2k + 1, for some integer k.
- The k is being given a name that it can be used in the rest of the proof.


CRITICAL RULE:
- If you introduce two different unkown integers, use "different names"
EX:
y = kx
AND
z = jx

NOT:
y = kx
AND
z = kx

- Since the same k would incorrectly imply that y = z.

-------------------------------------------------------------------------------------------------------------------------------

8. 5.2.5 - Valid/Invalid Existential Instantiation

1) "Since m^2 and n^2 are both even integers".
We can write: 
m^2 = 2k
AND
n^2 = 2j
- Where k and j are inteegrs.
Different objects get different names.
THUS: Valid



2) "m is odd and n is even so"
m = 2k + 1
AND
n = 2k

- Using the same k.
This is invalid because the two existential statements do not guarantee the same integer works for both.
Instead USE:
m = 2k + 1
AND
n = 2j
- with potentially different integers k, j.
THUS: INVALID

KEY RULE: Different existential choices -> different variable names.

9. Common Proof Mistakes

Mistake #1 - Generalizing from Examples
Showing:
8^2 = 64
- Doesn't prove that every even number has an even square.

WHY?
- You tested one number.
For a universal statement, use:
- Every possible value or
- A generic/arbitrary element.



Mistake #2 - Skipping Steps
Example: n = 2k + 1
THUS: n^2 = (2k + 1)^2
- and immediately claiming n^2 is odd.

The proof hasn't shown why.
- You need:
(2k + 1)^2 = 4k^2 + 4k + 1
= 2k(2k^2 + 2k) + 1

Since: 2k^2 + 2k
- Is an integer, the expression has the form:
2(integer) + 1
And is therefore odd.



Mistake #3 - Circular Reasoning
- Assumes the thing you're trying to prove.

EX: "Let n^2 = 2k + 1 for some integer j. Therefore n^2 is odd."
- But proving that n^2 has that form is the goal.
You can't assume your conclusion.

Shortcut
- Ask: "Did I assume the fact I'm supposed to prove?"
If yes -> circular reasoning.



Mistake #4 - Using an Unproven Fact
- A proof cannot suddenly use: "The product of two rational numbers is rational."

UNLESS the fact was:
- Already established, or
- Specifically allowed as an assumption.

RULE: Every non-obvious fact needs justification.

10. 5.2.6 - Find the Mistake

The theorem: "The difference between two odd numbers is even."

Proof #1
Line 1 introduces x, y.
Line 2 says: x = 2k + 1, y = 2j + 1
Line 3 suddenly states: "Since a and y are both odd, x - y must be even."

ISSUE:
- The proof hasn't actually demonstrated this: Mistake: Line 3.

What should have happened?
Calculate:
x - y = (2k + 1) - (2j + 1)
= 2k - 2j
= 2(k - j)
- Since k - j is an integer, x - y is even.



Proof #2
- This version perfomrs the necessaryu alegbra:
x - y = (2k + 1) - (2j + 1)
= 2(k - j)
- Then establishes that k - j is an integer.

THUS: Valid



Proof #3
It uses: 
x = 2k + 1
AND
y = 2k + 1
- Using the same k.
THUS: Incorrectly forces the two numbers to be equal.

MISTAKE: Line 2
- It should use different variables: x = 2k + 1, y = 2j + 1



Proof #4
- This version correctly uses: x = 2k + 1, y = 2j + 1
AND obtains: x - y = 2(k - j)
- The reasoning is valid because the difference of integers is an integer.
THUS: Valid.

11. 5.2.1 - Writing Proofs: Best Practices
- Select the valid proof steps/assumptions.


1) "Add 7 to both sides of x - 7 = 0 to get x = 7."
- Starting with:
x - 7 = 0

- Add 7:
x - 7 + 7 = 0 + 7

- Thus:
x = 7, VALID



2) "Square both sides of r = s/y to get r^2 = s^2/y^2."
- Squaring both sides:
r^2 = (s/y)^2

- And thus:
r^2 = s^2/y^2

- Is VALID, assuming the original fraction is defined.



3) "If x | z and y | z, then there exists an integer a such that x = az and y = az."
- This reverse the meaning of divisibility.

- IF: x | z
- THEN: z = ax
For some integer a.

It does not mean: x = az.
- Also, the two divisibility statement could require different integers.
THUS: INVALID.



4) "if x an y are integers, then either x is even or y is even."
- Counterexample: x = 1, y = 3
Both are integers, but both are odd.

THUS, the statement is false and INVALID.

12. Important Rules to Memorize:

- Every Proof step needs justification.
- Introduce variables before using them.
- Use complete sentences around mathematical expressio.
- Do not use the same existential variable for different objects.
- Do not prove a universal claim using only examples.
- Do not assume the conclusion.
- Do not use an unproven fact as if it were established.
