06 - 4.6 Greatest Common Divisor and Euclid's Algorithm

1. Euclid's Algoritm for Finding the GCD
- Finds the GCD without needing to find the prime factorizations.

Main operation: Repeatedly calculate y mod x

General process
Given two positive integers:
1) Start with the two numbers.
2) Calculate the remainder: r = y mod x
3) Replace the larger number with the smaller number.
4) Replace the smaller number with the remainder.
5) Repeat until the remainder is 0.
6) The last nonzero remainder is the GCD.

-------------------------------------------------------------------------------------------------------------------------------

2. 4.6.1 - Euclid's Algorithm
GCD(675,210)

Step 1 - First Division
Divide 675 by 210: 
: 675 = 3(210) + 45
Thus:
: 675 mod 210 = 45
So the next pair is:
: 210, 45


Step 2 - Repeat
Calculate:
: 210 mod 45
: 210 = 4(45) + 30
THUS:
: 210 mod 45 = 30
Next pair:
45, 30


Step 3 - Repeat again
: 45 mod 30 = 15
Next pair:
: 30, 15


Step 4 - Continue until remainder 0
: 30 mod 15 = 0
Stop.
- The last nonzero remainder was: 15
THUS:
: GCD(675, 210) = 15

Pattern to remember:
: 675 -> 210 -> 45 -> 30 -> 15 -> 0
- The solution is the number prior to 0.

4. Euclid's Algorithm - Quick Reference
For: GCD(x,y)
Use: x mod y
Then replace: (x,y) -> (y,r)

EX:
GCD(93, 48)
93 mod 48 = 45
48 mod 45 = 3
45 mod 3 = 0

THUS: GCD(93, 48) = 3

5. Extended Eucliden Algorithm
- Goes one step further.
Instead of only finding: GCD(x,y)
it finds integers s and t such that: GCD(x,y) = sx + ty
- Important for finding multiplicative inverses modulo n.

-------------------------------------------------------------------------------------------------------------------------------

6. 4.6.3 - Extended Euclidean Algorithm

GCD(675, 210) = 15

From Euclid's algorithm:
675 = 3(210) + 45
210 = 4(45) + 30
45 = 1(30) + 15

- The goal is to rewrite the final nonzero remainder 15 using only the original numbers 675 and 210.
Step 1 - Start with the GCD
15 = 45 - 30

Step 2 - Replace 30
From: 210 = 4(45) + 30
We get: 30 = 210 - 4(45)
Sub: 15 = 45 - (210 - 4(45))
Simplify: 15 = 5(45) - 210

Step 3 - Replace 45
From: 675 = 3(210) + 45
We get: 45 = 675 - 3(210)
Sub: 15 = 5(675 - 3(210)) - 210
Simplify: 15 = 5(675) - 16(210)
THUS: 15 = 5(675) - 16(210)

So: s = 5, t = -16

Work backward through the Euclidean equations:
Find GCD -> Solve remainders -> Substitute backward

7. 4.6.4 - Finding the Coefficients
For: GCD(225, 60)
First perform Euclid's Algorithm.

Step 1:
: 225 mod 60 = 45
So:
: 225 = 3(60) + 45


Step 2:
: 60 mod 45 = 15
So:
: 60 = 1(45) + 15


Step 3 - Stop
: 45 mod 15 = 0
THUS:
: GCD(225,60) = 15

NOW work backwards.
FROM:
: 60 = 45 = 15
We get:
: 15 = 60 - 45

From the first equation:
: 45 = 225 - 3(60)
Substitute:
: 15 = 60 - (225 - 3(60))
: 15 = 4(60) - 225
Therefore:
: 15 = (-1)(225) + 4(60)

So the coefficients are:
: C = -1 AND D = 4

9. Multiplicative Inverse Mod n
- A number x has a multiplicative inverse modulo n if there is a number s such taht:
sx mod n = 1
- Multiplying x by its inverse gives a remainder of 1.

EX: Find the inverse of 7 (mod 10)
Try: 7(3) = 21
Reduce modulo 10: 21 mod 10 = 1
Thus: 3
is a the multiplicative inverse of 7 (mod 10).

-------------------------------------------------------------------------------------------------------------------------------

10. When Does an Inverse Exist?
- An integer x has a multiplicative inverse modulo n only when:
GCD(x,n) = 1

So before trying to find an inverse:
Step 1:
Calculate: GCD(x,n)

Step 2:
If: GCD(x,n) != 1
THEN: No multiplicative inverse exits.

EX:
For 4 (mod 6);:
GCD(4,6) = 2
Since: 2 != 1
4 has no inverse modulo 6.

-------------------------------------------------------------------------------------------------------------------------------

11. Findin a Inverse by Inspection
For smaller numbers, you can simply test multiples.

EX: Find the inverse of 3 (mod 10).

We want: 3x mod 10 = 1
Tru Multiples:
3(1) = 3
3(2) = 6
3(3) = 9
3(4) = 12
12 mod 10 = 2

Continue until the remainder is 1:
3(7) = 21
21 mod 10 = 1

THUS: 3^-1 == 7 (mod 10)

Use inspections when:
- n is small.
- Testing a few values is practical.
For larger numbers, use the extended Euclidean algorithm.

12. Finding a Multiplicative Inverse Using Extended Euclid
Suppose: GCD(x,n) = 1

The extended Euclidean algorithm gives:
1 = sx + tn
Rearrange:
1 = sx + tn
Taking everything modulo n:
1 == sx (mod n)
THUS:
s is the inverse of x (mod n).
- If s is negative, reduce it modulo n.
