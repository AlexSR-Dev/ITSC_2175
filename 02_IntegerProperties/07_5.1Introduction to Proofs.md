07 - Introduction to Proofs

1. Identify the Type of Statement
- Detemine whether the statemen is "universal" or "existential".

Universal Statement - "for every"
- True for all elements in a domain.

Common Wording:
: "For every..."
: "For all..."
: "Any..."
: "Every..."

Symbol: ∀

EX: The sum of two rational numbers is rational.
- Applies to every pair of rational numbers.



Existential Statement - "there exists"
- At least one element exists with a particular property.

Common Wording:
: "There exists..."
: "There is..."
: "At least one..."

Synmbol: ∃

EX: There exists a positive integer x such that x^2 + 1 is divisible by 5.
- You only need one example that satisfies the condition.

4. Proof by Exhaustion
- Used when a universal statement has a small, finite number of possible values.

Step:
1) Identify the domain.
2) List every possible value.
3) Substitute each value into the statement.
4) Check whether the statement is true for every value.
5) If even one value fails, the universal statement is false.


EX Pattern:
Suppose:
n ∈ {−1,0,1}
- You need to check a statement involving n.
You would calculate the expression for:
n = -1
n = 0
n = 1
- Must check all three.

5. Activity 5.1.3 - Proof By Exhaustion
For every positive integer n less than 3, (n + 1)^2 >= 3^n.
- Key phrase: "Positive integer n less than 3."

Step 1 - List every possible n
Postive integers less than 3 are: 
n = 1, n = 2


Step 2 - Check n = 1
Substitute 1:
(n + 1)^2 > 3^n
(1 + 1)^2 > 3^1
2^2 > 3
4 > 3
- TRUE


Step 3 - Check n = 2
(2 + 1)^2 > 3^2
3^2 > 9
9 > 9
- FALSE, since 9 = 9, not 9 > 9.

RESULTING: The statement itself is FALSE.

6. Universal Generalization
- Used when there are too many possible values to check individually.
Choose an arbitrary element from the domain.

General procedure
Suppose the statement says:
"Every positive integer satisfies some property."

Start with: "Let x be an arbitrary positive integer."
THEN:
1) State the assumptions about x.
2) Work through the algebra/reasoning.
3) Show that the required conclusion follows.
4) Since x was arbitrary, the result applies to every element in the domain.


Use: x = an arbitrary element of the domain.

8. Choosing the Correct Beginning of a Proof
- The key is to match the opening to the type of statement.


If the statement concerns arbitrary real numbers:
- Use "Let x and y be two real numbers."

If it concerns arbitrary integers:
- Use "Suppose x and y are integers."

If it concerns odd integers:
- Use "Suppose x and y are odd integers."

If it concerns consecutive integers:
- Start with "Let x and y be two consecutive integers."
- or represent them algebraically: y = x + 1

Key Rule: The opening must contain the same assumptions as the original statement.

10. Counterexamples
- Used to show that a universal statement is false.

Important rule
To disprove: Every x has property P.
You only need: ONE value that does not have property P.

General Procedure:
1) Read the universal statement.
2) Find a value in the stated domain.
3) Test the statement using that value.
4) If the conclusion is false, you have a counterexample.
5) The universal statement is therefore false.

EX:
Suppose someone claims: For every integer n > 2, (n + 1)^n < n^2
-You do not need to test every integer.
- Just find one value, like n = 686, that the statement fails, is a counterexample.
THUS: The universal statement is false.

-------------------------------------------------------------------------------------------------------------------------------

11. Counterexample != Just Any Example
Suppose the statement is:
"For every real number x, P(x) is true."
You Need: P(x) is false.

REMINDER:
True Example: Supports the statement but does not prove it universally.
Counterxample: Shows the universal statement is false.

13. Counterexamples for Conditional Statements
A conditional statement has the form:
If H, then C

: H = hypothesis
: C = Conclusion

To find a counterexample:
You need:
H = True
AND
C = False

NOTE:
Counterexample = satisfies the hypothesis + violates the conclusion.

-------------------------------------------------------------------------------------------------------------------------------

14. Conditional Counterexample EX
Suppose: "For any real number x, if 0 < x < 1, then x^2 < x."
- To find a counterexample, test a number.

Step 1: Check the hypothesis
You need: 0 < x < 1

Step 2: Check the conclusion
You need the conclusion to be false: x^2 !< x

A valid counterexample must satisfy both of these conditions:
0 < x < 1
OR
x^2 >= x

TRAP:
- A number outside the hypothesis is NOT a counterexample.
EX: x = 2, won't work since 2 < 1 is false.

17. Proving an Existential Statemment
- An existential statement claims: ∃x
At least one value exists.

- To prove it, you'll only need to find one valid example.

General steps:
1) Identify what the statement requires.
2) Find a possible value.
3) Substitute it into the condition.
4) Verify that it works.
5) Stop - one valid example is enough.


EX:
Statement: "There exists an integer x such that x^2 = 9."
Try: x = 3
Then: 3^2 = 9
THUS: x = 3 proves the existential statement.

19. Nested Existential Statement

For every integer x, there is an integer y such that y + 3 = x.

Important part: ∀x ∃y
- Means: "For every x, we must be able to find some y."

Step 1:
- Start with arbitrary integer x.

Step 2:
Solve: y + 3 = x
For y.
Subtract 3: y = x - 3

Step 3:
Because x is an integer: x - 3
Is also an integer.

Step 4:
Verify: y + 3 = (x - 3) + 3 = x
- Thus, the statement works.

General Strategy
- When you see: ∀x ∃y
Begin with arbitrary x, then construct y.

20. Activity 5.1.8 - Disproving an Existential Statement
- The reverse of proving an existential statement

Suppose: "There exists an integer x satisfying P(x)."
- To prove that statement false, you need to establish:
"Every integer fails P(x)."

So: Disprove ∃ -> prove ∀ fails


Q1: "There is an integer x that satisfies"
: x^2 - x = 1
- "Which statement must be proven to show that the statement is false?"
- The original statement says: ∃x ∈ Z

We need to show: ∀x ∈ Z, x^2 − x != 1
- Thus, the correct choice is: "Every integer x satisfies x^2 - x != 1."


WHY?
- Start with: x^2 - x = 1
- Move everything to one side: x^2 - x - 1 = 0
- Using the quadratic formula:
x = (1 +- sqr(1 + 4))/2
x = (1 +- sqrt(5))/2
- Neither solution is an integer because: sqrt(5) is irrational.
THUS: There is not integer satisfying the original equatio.

SO: "Every integer x satisfies x^2 - x != 1"
- Is the statement needed to disprove the existential claim.





Q2: "There are two distinct integers whose sum is equal to their product."
- Mathematically: 
x != y
AND
x + y = xy

- The statement is existential as: "There are two distinct integers"
- To prove it false, we must say that no such pair exists.

THUS, the corresponding universal statement is:
"For every pair of integers x,y, if x != y, then xy != x + y"

General Pattern
Original: ∃x,y : P(x,y)
To Disprove: ∀x,y : ¬P(x,y)

Rule 1 - Proving a universal statement
- You must cover every possibility.
For a small finite domain: Use exhaustion.
For a large/infinite domain: Use a arbitrary element.


Rule 2 - Disproving a universal statement
- You only need: "ONE counterexample"


Rule 3 - Proving an existential statement
- You only need: "ONE sucessful example"


Rule 4 - Disproving an existential statement
- You must establish that: "Every possible element fails"
