16 - 6.4 Composition of Relations

1. Composition of Relations
Suppose R and S are relations on a set A.
- The composition of R and S is another relation on A, written: S o R
- An ordered pair (a,c) belongs to S o R if and only if there is some b ∈ A such that:
: (a,b) ∈ R
AND:
: (b,c) ∈ S

THUS: (a,c) ∈ S o R <--> ∃b ∈ A such that (a,b) ∈ R and (b,c) ∈ S

RECOGNIZE:
When you see: S o R
- translate to "R first -> S second"

The process goes:
  R    S
a -> b -> c  =>  (a,c) ∈ S o R

THUS:
1) Start at a.
2) Follow an R-edge
3) Arrive at an intermediate vertex b.
4) Follow an S-edge.
5) Arrive at c.
6) Record (a,c).


WHY is the order S o R?
- Its the comparison with function composition.
IF: S o R
THEN: R is applied first and S is applied second.
R -> S

2. The Core Recognition Pattern
- When the question asks: "Is (a,c) ∈ S o R?"
: Don't look for the direct a -> c edge.

- Instead ask: "Can I find some intermediate vertedx b such that a -> b using R, and then b -> c using S?"
Symbolic Form:
  R    S
a -> b -> c

- IF such a "b" exists:
(a,c) ∈ S o R
- If no such "b" exists:
(a,c) !∈ S o R

3. 6.4.1 - Composition of Relations
- The lesson gives relations R and S on:
A = {a,b,c,d}
- And asks you to understand the resulting relation:
S o R

TESTS: Composing two relations by following two consecutive directed edges.
- The first edge must come from R.
- The second edge must come from S.


APPROACH:
- For every possible route:
                R                S
starting vertex -> middle vertex -> ending vertex

Record: (starting vertex, ending vertex)
NOTE:
- Intermediate vertex is NOT included in the resulting ordered pair:
EX:
  R    S
a -> b -> d

RESULTS: (a,d)
NOT: (a,b,d)

4. 6.4.2 - Composition of Relations
ASKS: Provides two relations R and S on:
{a,b,c,d}
- And asks four questions in the form: "Is (x,y) in S o R?"

THUS, do not simply determine whether x -> y appears in either diagram.
- You must determine whether there is a two-step route:
  R    S
x -> z -> y
- For some intermediate z.


1) First Identify the Relations:
Relation R
- The directed edges are:
d -> a
a -> b
b -> c
THUS: R = {(d,a), (a,b), (b,c)}


Relation S
- The displated arrows give:
a -> a
b -> d
b -> c
THUS: S = {(a,a), (b,d), (b,c)}

- The self-loop at a is important: (a,a) ∈ S


Q1) Is (a,d) ∈ S o R?
ASKS: Can we get from a to d by: R first -> S second?
APPROACH:
Start at "a" and follow R.

From a:
   R
a -> b
- Now switch to S.
From b:
   S
b -> d

THUS:
   R    S
a -> b -> d

RESULTS: YES

WHY?
- There exists an intermediate vertex "b" such that:
: (a, b) ∈ R
AND:
: (b,d) ∈ S

THUS: (a,d) ∈ S o R



Q2) Is (b,d) ∈ S o R?
- Asks:
   R            S
b -> something -> d?

Step 1 - Follow R
From b:
   R
b -> c

Step 2 - Swtich to S
- There is no outgoing S-edge in the displayed relation.
Thus:
   R   S
b -> c -> d
- Is Invalid.
RESULT: NO



Q3) Is (b,c) ∈ S o R?
- Asks, can we travel from b to c using: R -> S?

Step 1 - Follow R
From b: b -> c

Step 2 - Follow S
- We need an S-edge leaving c.
BUT there isn't one.
THUS, the required two-step route DNE.

RESULT: NO



Q4) Is (d,a) ∈ S o R?
ASKS: Can we go R -> C, by traveling from d to a?

Step 1 - Follow R
From d: d -> a

Step 2 - Follow S
- From a, S contains the self-loop: a -> a
        R     S
THUS: d -> a -> a
RESILT: YES
