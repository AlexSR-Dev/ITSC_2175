18 - 6.6 Properties of Binary Relations

GOAL: Determine whether a binary relation is
: Reflexive
: Anti-Reflexive
: Symmetric
: Anti-Symmetric
: Transitive

STATEGY:
Question -> Identify the required condition -> Look for the required pattern -> Conclude
- Properties defined by "for every", one counterexample should show the property fail.

-------------------------------------------------------------------------------------------------------------------------------

1. 6.6.1 Reflexive and Anti-reflexive Binary Relations
Reflexive - A relation R and A is reflexive if: ∀x ∈ A, xRx
- Every element must be related to itself.

RECOGNIZE:
aRa, bRb, cRc,...
- In an arrow diagram, every element must have a self-loop.


Anti-reflexive
- A relation R on A is anti-reflexive if: ∀x ∈ A, -(xRx)
- No element may be related to itself.

RECOGNIZE:
- There must be NO SELF-LOOPS in an arrow diagram.

NOTE:
- A relation can be neither reflexive nor anti-reflexive.
EX:
: aRa is true.
: bRb is false.
- It not reflexive because bRb fails, and not anti-reflexive because aRa is true.

-------------------------------------------------------------------------------------------------------------------------------

2. 6.6.1 Activity:
- Uses arrow diagrams.
TESTS: Whether the relation contains:
: Every possible self-loop -> reflexive
: No self-loop -> anti-reflexive
: Some but not all self-loops -> neither

- Identify reflexive and anti-reflexive binary Relations:
: The domain is the set of all positive real numbers.

Q1) xRy if y = x + 1
- For reflexivity, substitute y = x:
: x = x + 1
- This is impossible.
RESULT: Anti-reflexive
WHY?
- No positive real number is related to itself.


Q2) xRy if y = 1/x
- For reflexivity:
: x = 1/x
: x^2 = 1
- Since the domain is positive real numbers: x = 1
- THUS: 1R1 is true, but not every element relates to itself.
RESULT: Neither
WHY?
- Not reflexive: most x do not satisfy x = 1/x
- Not anti-reflexive: 1R1 is true.


Q3) xRy if |x| <= |y|
- For any x, |x| <= |x|
is always true.
RESULT: Reflexive

-------------------------------------------------------------------------------------------------------------------------------

3. Symmetric Binary Relations
- A relation R on A is symmetric if:
∀x,y ∈ A, xRy <--> yRx
- If x relates to y, then y must relate back to x.

RECOGNIZE:
- For every pair: xRy <---> yRx
- In an arrow diagram: x -> y
: must be accompanied by: y -> x

THUS:
1) Find an arrow x -> y
2) Check for y -> x
3) If one arrow lacks it reverse -> not symmetric
4) If every arrow has its reverse -> symmetric

NOT:
- For self-loops, a loop x->x is its own reverse.

-------------------------------------------------------------------------------------------------------------------------------

4. 6.6.3 Activity
- Symmetric Binary Relations
The allowed patterns are:
: Neither xRy nor yRx
: Both xRy and yRx

The disallowed patterns are:
: xRy but not yRx
: yRx but not xRy

RECOGNIZE:
Symmetric = arrows come in pairs

-------------------------------------------------------------------------------------------------------------------------------

5. 6.6.4 Activity
- Identifying symmetric Relations

Q1) xRy if x/y = 2
- Meaning: x = 2y
- The reverse would require: y = 2x

- These cannot both hold for positive real numbers.
RESULT: Not symmetric


Q2) xRy if y = 1/x
- Equivalent to: xy = 1
- If y = 1/x, then: x = 1/y

- So the relationship works in both directions.
RESULT: Symmetric

-------------------------------------------------------------------------------------------------------------------------------

6. Anti-symmetric Binary Relations
- A relation R on A is anti-symmetric if for every distinct x, y ∈ A,
xRy and yRx
- Cannot both be true.

Formally: x != y AND xRy AND yRx
- Must NEVER occur.

RECOGNIZE:
- For two different elements:
: x -> y only -> allowed
: y -> x only -> allowed
: neither -> allowed
: both -> NOT allowed 

- LOOK for:
x != y, xRy, yRx
- Finding any of these pair -> not anti-symmetric

NOTE:
- Two distinct elements cannot relate to each other in both directions.

-------------------------------------------------------------------------------------------------------------------------------

7. 6.6.5 Activity
- Anti-symmetric binary relations
Allowed:
: Neither xRy nor yRx
: xRy but not yRx
: yRx but not xRy

Disallowed: xRy and yRx, x != y

-------------------------------------------------------------------------------------------------------------------------------

8. 6.6.6 Activity
- Identifying anti-symmetric relations

Q1) xRy if |x| <= |y|
- This relation is not symmetric because, for instance different numbers can have the same floor and thus relate in both directions.
- Since distinct values can satisfy both directions:
RESULT: Neither


Q2) xRy if x + y = 1
- The condition is unchanged when x and y are switched:
x + y = 1 <---> y + x = 1

RESULT: Symmetric
- It is not anti-symmetric because distinct positive numbers can satisfy the condition in both directions.


Q3) xRy if y = x + 1
- The reverse would require: x = y + 1
- Both cannot be true simultaneously.
THUS: there cannot be distinct x, y with both xRy and yRx.
RESULT: Anti-symmetric

-------------------------------------------------------------------------------------------------------------------------------

9. Transitive Binary Relations
- A relation R on A is transitive if: xRy and yRx -> xRz
- For every x,y,z ∈ A.

RECOGNIZE:
- Look for a chain: x -> y -> z
- Then there must also be: x -> z

1) Find xRy
2) Find yRz
3) Check whether xRz
4) If you find one chain where xRz is missing -> not transitive.
5) If no forbidden chain exists -> transitive.

TRAP:
- Elements x,y,z do not have to be distinct.

-------------------------------------------------------------------------------------------------------------------------------

10. 6.6.7 Activity
- Transitive binary relations
The forbidden pattern is: xRy, yRz, but not xRz

- Those single pattern proves a relation is not transitive.

-------------------------------------------------------------------------------------------------------------------------------

11. 6.6.8 Activity
- Identifying transitive relations

Q1) xRy if y = x + 1
Suppose: xRy, yRz
Then: y = x + 1
AND: z = y + 1 = x + 2

But transitivity would require: z = x + 1
- Which is false.

RESULT: Not transitive 


Q2) xRy if y >= x + 1
Suppose: y >= x + 1
AND: z >= y + 1
THEN: z >= x + 2
THUS: z >= x + 1

SO: xRz
RESULT: Transitive


Q3) xRy if |x| <= |y|
IF: |x| <= |y|
AND: |y| <= |z|
THEN: |x| <= |z|

RESULT: Transitive

14. Proving and Disproving Properties of Binary Relations
- Each property is states as a universal condition.

THUS: 
- To prove a property:
: You must show the condition holds for all elements required by the definition.

- To disprove a property:
- You only need one counterexample.

EX:
- The domain is the set of all 4-bit strings.
Two strings are related if they have:
: The same first bit, or
: The same last bit.

For instance: 1001R0101
- Because both have the same last bit.
BUT:
1001 R0100
- Because neither their first bits nor their last bits match.

-------------------------------------------------------------------------------------------------------------------------------

15. 6.6.11 Activity
- Justifying that a relation does or does not have a property

1) Reflexive
- To show R is reflexive: ∀x, xRx
- Every binary string has the same first bit as itself.

THUS: R is reflexive.


2) Symmetric
- To show R is symmetric: xRy -> yRx
- If x and y have the same first or last bit, then y and x also have the same first or last bit.

THUS: R is symmetric.


3) Transitive
- R is not transitive using a counterexamples: 1001R1000
- Because they share the first bit. 

BUT: 1001 R0000
- Because neither their first bits nor their last bits match.
THUS: R is not transitive.

16. 6.6.12 Activity
- Recognizing properties: Integer multiples
The domain is the positive integers: xDy
- If x evenly divides y.

1) Reflexive, anti-reflexive, or neither?
- Every positive integer divides itself: x | x
RESULT: Reflexive


2) Symmetric, anti-symmetric, or neither?
IF: x | y
- It does not necessarily mean: y | x

For instance: 2 | 4
BUT: 4 !| 2

HOWEVER, if both x | y and y | x, then for positive integers: x = y
RESULT: Anti-symmetric


3) Is it transitive?
If: x | y
AND: y | z
THEN: x | z

RESULT: Transitive

17) 6.6.13 Activity
Recognizing properties: Relatively prime positive integers
- The domain is the positive integers.
: xPy
- If x and y are relatively prime.
Two positive integers are relatively prime when their only common positive divisor is: 1.


Q1) Select the pair for which xPy is true.
Choices:
: x = 7, y = 7
: x = 8, y = 27
: x = 15, y = 18

CHECK: gcd(8,27) = 1
RESULT: x = 8, y = 27


Q2) Is P reflexive, anti-reflexive, or neither?
- For reflexiviity, every number would need to be relatively prime to itself.
BUT: gcd(2,2) = 2
- So 2P2 is false.

HOWEVER: gcd(1,1) = 1
- So 1P1 is true.
RESULT: Neither


Q3) Is P symmetric, anti-symmetric, or neither?
- Relative primality is unchanged when the two numbers are switched:
gcd(x,y) = gcd(y,x)
RESULT: Symmetric


Q4) Select the triple showing P is not transitive.
Need: xPy, yPx, but xPz

TEST: (4,7,6)
gcd(4,7) = 1
gcd(7,6) = 1

BUT: gcd(4,6) = 2
THUS: 4P7, 7P6, 4P6
RESULT: 4,7,6
