1. Integer Division
- Division is integer division.
EX: 9 / 4
- Is not written as: 2.25
Instead, integer division gives: 9 = 4(2) + 1

THUS:
• Quotient = 2
• Remainder = 1

Fundamental Idea:
Dividend = (Divisor)(Quotient) + Remainder

- Becomes Division Algorithm.

-------------------------------------------------------------------------------------------------------------------------------

2. Divisibility Review

- For integers x and y, x | y

if and only if:
1) x != 0, and
2) There is an integer k such that: y = kx

If x does not divide y, we write: x ∤ y.


IF: x | y
• x is a factor of y.
• x is a divisor of y.
• y is a multiple of x.


EX: 6 | 24
Because: 24 = 6(4)
THUS:
• 6 is a factor of 24.
• 6 is a divisor of 24.
• 24 is a multiple of 6.

3. Linear Combinations
- Of two integers x and y is an expression of the form:
: sx + ty
- s and t are integers.

EX: 3x - 7y
AND
-2x + 4y

- Are linear combinations of x and y.
- The coefficients are integers.

-------------------------------------------------------------------------------------------------------------------------------

4. Theorem: Divisibility and Linear Combinations

Theorem:
Let x, y, z be integers.

If: x | y
And: x | z
Then: x | (sy + tz)
- For any integers s and t.



Its evaluation:
IF: 
x | y

Then there is an integer k such that:
y = kx

Likewise, if:
x | z

Then there is an integer j such that:
z = jx

Now consider the linear combination:
sy + tz

Substitute the expressions for y and z:
sy + tz = s(kx) + t(jx)

Distribute:
        = skx + tjx

Factor out x:
        = x(sk + tj)

Since s,t,k,j are integers,
        sk + tj
Is also an integer.

THUS:
sy + tz = x(integer)

Meaining: x | (sy + tz)

5. Worked Example:

1. 6 | 12 and 6 | 18  to  6 | 462
- 6 must divide any integer linear combination of 12 and 18.

Consider: 19(12) + 13(18)
Calculate: 19(12) = 228
And: 13(18) = 234

Thus: 228 + 234 = 462
So: 462 = 19(12) + 13(18)

Since 6 divides both 12 and 18, the theorem is: 6 | 462
Verified with: 462 = 6(77) and 77 is an integer.

6. 4.2.1 - Integer Divisibility

1) Does 7 divide 56?

- Asks whether there is an integer k such that: 56 = 7k
Divide: k = 56/7 = 8
Since: 8 ∈ Z

We have: 56 = 7(8)
THUS: Yes



2) 7(18) + 14(17) = 364. Does 7 divide 364?

Start with: 7(18) + 14(17)

Notice: 14 = 7(2)
Thus: 7(18) + 14(17), is rewritten to:
7(18) + 7(2)(17)

Factor out 7: 7[18 + 2(17)]
Calculate: 18 + 34 = 52
Thus: 364 = 7(52)

Since 52 is an integer: 7 | 364
RESULTING: Yes

- This is an applciation of the linear-combination theorem.

7. Quotients and Remainders
- If x does not divide y, division produces a nonzero remainder.

EX: 9 = 4(2) + 1
• quotient is 2
• remainder is 1

- The Division Algorithm formalizes this process.

-------------------------------------------------------------------------------------------------------------------------------

8. The Division Algorithm

Theorem 4.2.2
- Let n be an integer and let d be a positive integer.

Two unique integers q and r such that:
      n = qd + r
AND
      0 <= r <= d - 1

Equivalently:
      0 <= r < d


9. What Each Variable Means:
In: n = qd + r

n - The number being divided. Dividend
d - The positive number you divide by. Divisor
q - The integer produced by division. Quotient
r - What remains after taking out as many copies of d as possible. Remainder


MEMORIZE NOTE:
n = qd + r
With:
0 <= r < d



10. Why the Remainder has a Restricted Range
Suppose: n = qd + r
With: 0 <= r < d

The remainder cannot be negative.
It also cannot be equal to or greater than the divisor.

EX: dividing by 6, possible remainders are:
: 0,1,2,3,4,5

But never: 6
Because: 6 = 6(1) + 0
Thus having a remainder of 6 simply means the quotient was not taken far enoough.
Resulting: r < d is needed.

11. Div and Mod

q = n div d
AND:
r = n mod d

div - Returns the quotient: n div d = q

mod - Returns the remainder: n mod d = r


EX: Divide 15 by 6.
We want: 15 = 6p + r

The largest multiple of 6 that does not exceed 15 is: 6(2) = 12
Subtract: 15 - 12 = 3
Thus: 15 = 6(2) + 3
So:
15 div 6 = 2
AND:
15 mod 6 = 3

-------------------------------------------------------------------------------------------------------------------------------

12. Negative Numbers and Mod

The remainder must satisify: 0 <= r < d
even when n is negative.

EX: -7 mod 4
- We need to express -7 in the form: -7 = 4q + r
Where: 0 <= r < 4

The possible remainders are: 0,1,2,3
Try: -7 = 4(-2) + 1
Because: 4(-2) = -8
AND: -8 + 1 = -7

Thus: -7 div 4 = -2
AND: -7 mod 4 = 1


Critical Thought
You would think of: -7 = 4(-1) - 3
Which provides a remainder of -3.

BUT this violates: 0 <= r < 4
Beacause -3 is negative.

Thus, under the Division Algorithm convention used: -7 mod 4 = 1

13. Procedural Version of the Division Algorithm

The input is: 
n, d > 0

And the output is:
q = n div d
r = n mod d


Case 1: n >= 0
Start with: q = 0
            r = n

Then repeatedly:
q = q + 1
r = r - d

While:
r >= d
The process stops once: r > d


Case 2: n < 0
Start with:
q = 0
r = n

Then repeatedly:
q = q - 1
r = r + d

While:
r < 0

The process stops when:
r >= 0

This guarantees:
0 <= r < d

20. Proof of Divisibility Statements:

To prove: a | b
You must show: b = ak
For some: k ∈ Z

To disprove:
a | b
- You need to show that no such integer k exists, thus a counterexample.

-------------------------------------------------------------------------------------------------------------------------------

21. Linear Combination Proof Template

If given: a | b
Write: b = ak
for some integer k

If also: a | c
Write: c = aj
for some integer j.

Then for: sb + tc
Substitute:
s(ak) + t(aj)

Factor:
a(sk + tj)
Since:
sk + tj ∈ Z

Conclude with:
a | (sb + tc)
