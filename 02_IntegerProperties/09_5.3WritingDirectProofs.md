09 - 5.3 Writing Direct Proofs

1. What this Section Teaches

Main Goals:
- Identify the hypothesis and conclusion of a conditional theorem.
- Identify what assumptions must be made at the beginning of a direct proof.
- Recognized the basic structure of a direct proof.
- Write a direct proof by starting with the hypothesis and logically reaching the conclusion.

Main Idea;
A direct proof follows this basic pattern:
Asssume the hypothesis -> use the assumption -> prove the conclusion.

For a condition statement:
If p, then c
- p = hypothesis
- c = conclusion

-------------------------------------------------------------------------------------------------------------------------------

2. The Form of a Direct Proof
- Usually begins by:
1) Naming the object(s) being discussed.
2) Stating all the assumptions about those objects.
3) Saying what you intend to prove.
4) Using definitions and algebraic reasoning.
5) Reaching the conclusion.

EX:
Theorem: "The square of every odd integer is also odd."
Beginning of the proof: "Let n be na integer taht is odd. We will show that n^2 is also odd."

How to recognized the assumptions
- The theorem says: "If n is an odd integer, then n^2 is odd."

THUS: the direct proof begins with:
- n is an integer.
- n is odd.
: The statement n^2 is odd is not an assumption - it is the "conclusion" that must be proven.

-------------------------------------------------------------------------------------------------------------------------------

3. 5.3.1 - Assumptions in a Direct Proof
- Match each theorem with the assumptions that should appear at the beginning of its direct proof.

Theorem #1
- "The difference between two distinct real numbers is not equal to zero."

Correct assumptions: "Let x and y be real numbers such that x != y."
WHY?
- The theorem involves two numbers -> introduces x and y.
- They are real -> state that.
- They are distinct -> x != y.



Theorem #2
- "The average of two real numbers is greater than or equal to at least one of the numbers."

Correct assumptions: "Let x and y be real numbers."
WHY?
- The theorem only specifies that the two numbers are real. It does not say that they must be positive or different.



Theorem #3
- "The product of two positive real numbers is a positive number."

Correct assumption: "Let x and  y be real numebrs such that x > 0 and y > 0."
WHY?
- The hypothesis specifically requires both numbers to be positive real numbers.
Recognition Rule:
- When an activity asks for the assumptions: "Look at the "if" portion of the theorem."
Those conditions becomes the assumptions at the beginning of the direct proof.

-------------------------------------------------------------------------------------------------------------------------------

4. Writing a Direct Proof
- Once the assumptions are established, the proof works toward the conclusion.

Then general process is:
Step 1 - Introduce the object
- "Let n be an integer that is odd."

Step 2 - State the goal
- "We will show that n^2 is also odd."

Step 3 - Use the definition
- An odd integer can be written as: n = 2k + 1
- Where k is an integer.

Step 4 - Work toward the conclusion
- Substitute 2k + 1 for n: n^2 = (2k + 1)^2
- Then simplify until the expression has the form: 2m + 1
- Where m is an integer.

Step 5 - State the conclusion
- Because the result has the form 2m + 1, n^2 is odd.

Key Pattern, for direct proof involving definitions:
Assumption -> Definition -> Algebra -> Required Form -> Conclusion.

5. Worked Example - Square of an Odd Integer

Theorem - "The square of every odd integer is also odd."

Step-by-step
1) Assume the hypothesis
- Let n be an odd integer.

2) State what must be proven
- We need to show that n^2 is odd.

3) Use the definition of odd
- Since n is odd: n = 2k + 1, for some integer k.

4) Square the expression
n^2 = (2k + 1)^2

5) Simplify
n^2 = 4k^2 + 4k + 1

Rewrite:
n^2 = 2(2k^2 + 2k) + 1

6) Identify the required form
- Since k is an integer,
2k^2 + 2k is also an integer.

Let: m = 2k^2 = 2k
Then: n^2 = 2m + 1
THEREFORE: n^2 is odd.

Recognize the strategy: "To prove something is odd, try to get it into the form 2(integer) + 1."

6. The Process of Writing Proofs

When developing a proof it is normal to:
- Try examples.
- Experiment with algebra.
- Try different approaches.
- Reach dead ends.
- Work backward to understand what expression is needed.
- Important distinction

DISTINCTION:
- Scratch work ≠ final proof
- Scratch work can be messy and exploratory.
- The final proof should present the successful logical path clearly and directly.

7. Worked Example - Algebraic Direct Proof
- "If x and y are positive real numbers, then x/y + y/x >= 2."

Step-by-step structure
1) Assume the hypothesis
- x and y are positive real numbers.

2) Use a known fact
- Since x - y is real: (x - y)^2 >= 0
Because the square of a real number cannot be negative.

3) Expand
x^2 - 2xy + y^2 >= 0

4) Use Positivity
- Since x > 0 and y > 0,
xy > 0
so the inequality can be divided by xy.
Giving: x/y - 2 + y/x >= 0

5) Rearrange
- Add 2:
x/y + y/x >= 2

NOTE: Start with the assumptions → use a fact that follows from them → manipulate the result → reach the conclusion.

8. 5.3.4 - Direct Proof: Algebraic Theorem
- "If x is a real number and x - 3 = 0, then x^2 - 2x - 3 = 0."

Correct Order
1) Start with the assumptions
- "Assume x is a real number and x - 3 = 0. We shall prove that x^2 - 2x - 3 = 0."

2) Solve the given equation
- "Add 3 to both sides of x - 3 = 0 to get x = 3."

3) Substitute
- "Plug in x = 3 into the exrpession x^2 - 2x - 3."

4) Calculate
x^2 - 2x - 3 = 3^2 - 2(3) - 3 = 9 - 6 - 3 = 0

5) Conclude
- "Therefore, when x - 3 = 0 is true, x^2 - 2x - 3 = 0 is also true."


Recognition Strategy: Get the information from the hypothesis into a form that can be substituted into the conclusion.

9. Direct Proofs About Rational Numbers

Main Idea:
- If r is rational, it can be represented as: r = a/b

Where:
- a and b are integers.
- b != 0.

For two rational numbers, use "different variables" for their numerators and denominators:
r = a/b
s = c/d
- Where a,b,c,d are integers and b,d != 0.

- Do not assume they share the same integers.

-------------------------------------------------------------------------------------------------------------------------------

10. 5.3.5 - Sum the Two Rational Numbers
- "If r and s are rational numbers, then r + s is a rational number."

Step-by-step
1) Assume the hypothesis
- r and s are rational.

2) Use the definition
- There are integers a,b,c,d such that:
r = a/b, s = c/d
WITH:
b != 0, d != 0

3) Add the fractions
r + s = a/b + c/d
= ad + cb / bd

4) Check the numerator
- Since a,b,c,d are integers:
ad + cb
is an integer.

5) Check the denominator
- Since b != 0 and d != 0:
bd != 0

6) Match the definition
- r + s is therefore a ratio of two integers with a nonzero denominator.
Conclusion: r + s, is rationl

When proving something is rational you target is: integer/nonzero integer
